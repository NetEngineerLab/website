Sobre e abrangência

Use isto para blocos independentes. Não modela alimentação compartilhada, software comum nem um calendário de manutenção. A indisponibilidade anual usa um ano de 365 dias.

Esta é uma aproximação de engenharia para planejamento. Não é uma medição de laboratório e não garante o desempenho do equipamento.

Revisado: 2026-11-19

Como o cálculo é feito

Série A = ∏ A_i. Paralelo A = 1 − ∏(1 − A_i). A = MTBF / (MTBF + MTTR).

Se cada bloco falha de forma independente, a disponibilidade em série é o produto das disponibilidades. A disponibilidade em paralelo é um menos o produto das indisponibilidades. Dois caminhos de 0.999 em paralelo dão 1 − 0.001×0.001 = 0.999999. MTBF e MTTR na mesma unidade de tempo dão A = MTBF / (MTBF + MTTR). Os minutos de indisponibilidade esperados em 365 dias são (1−A)×525600. Informe as disponibilidades como frações de pouco acima de 0 até 1, um bloco por vírgula.

Perguntas

O paralelo sempre supera a série?

Para os mesmos blocos independentes, a combinação em paralelo é maior.

A disponibilidade pode ser exatamente 1?

Sim. A indisponibilidade então é zero neste modelo.

Por que zero é recusado?

Um bloco zero precisa de um modelo de falha diferente de uma disponibilidade positiva.

0.999999 é um SLA medido?

Não. É a aritmética de dois blocos de 0.999.
