About and applicability

Use this for independent blocks. It does not model shared power, common software, or a maintenance calendar. Annual downtime uses a 365-day year.

This is an engineering approximation for planning. It is not a laboratory measurement and it does not guarantee equipment performance.

Content reviewed: 2026-11-19

How it is calculated

Series A = ∏ A_i. Parallel A = 1 − ∏(1 − A_i). A = MTBF / (MTBF + MTTR).

If each block fails independently, series availability is the product of the availabilities. Parallel availability is one minus the product of the unavailabilities. Two paths at 0.999 in parallel give 1 − 0.001×0.001 = 0.999999. MTBF and MTTR in the same time unit give A = MTBF / (MTBF + MTTR). Expected down minutes in 365 days are (1−A)×525600. Enter availabilities as fractions from just above 0 through 1, one block per comma.

FAQ

Does parallel always beat series?

For the same independent blocks, the parallel combination is higher.

Can availability be exactly 1?

Yes. Downtime is then zero in this model.

Why reject zero?

A zero block needs a different failure model than a positive availability.

Is 0.999999 a measured SLA?

No. It is the arithmetic of two 0.999 blocks.
