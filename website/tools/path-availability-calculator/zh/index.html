关于与适用范围

用于相互独立的分块。它不表示共享电源、共同软件或检修日历。年停机时间按 365 天计算。

这是规划用的工程近似，不是实验室实测，也不保证设备实际性能。

内容复核：2026年11月19日

计算方法

Series A = ∏ A_i. Parallel A = 1 − ∏(1 − A_i). A = MTBF / (MTBF + MTTR).

如果各分块独立失效，串联可用度是各可用度的乘积。并联可用度是 1 减去各不可用度的乘积。两条 0.999 的并联路径得到 1 − 0.001×0.001 = 0.999999。同一时间单位下的 MTBF 和 MTTR 给出 A = MTBF / (MTBF + MTTR)。365 天的期望停机分钟数是 (1−A)×525600。可用度用大于 0 到 1 的小数，逗号分隔。

问答

并联是否总是高于串联？

对同一组独立分块，并联合成更高。

可用度可以正好是 1 吗？

可以。此时本模型的停机时间为 0。

为什么拒绝 0？

零可用度需要另一套失效模型。

0.999999 是实测 SLA 吗？

不是。它是两个 0.999 分块的运算结果。
