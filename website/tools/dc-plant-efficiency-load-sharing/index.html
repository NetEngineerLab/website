What this analyzer diagnoses

The tool compares each online rectifier current with the plant mean, identifies large positive or negative sharing deviations, checks rated loading and tests whether the remaining modules can carry the present load after the selected redundancy loss.

Efficiency should use measured AC input

When measured AC input is supplied, the analyzer estimates DC output from bus voltage × total measured DC current, then calculates conversion efficiency and loss. Use values measured at the same operating point and avoid mixing controller estimates with unrelated meter readings.

Interpretation boundary

Unequal current sharing can be caused by module condition, controller logic, current-limit settings, voltage calibration, wiring resistance or transient load behavior. Treat this page as an engineering diagnostic screen, not as proof that a specific rectifier is faulty.

DC plant load-sharing method
Total current = Σ module currents
Deviation = |module current − mean| / mean × 100%
Plant efficiency ≈ DC output / AC input × 100%

Current balance

Compare each rectifier or converter module current to the mean to find load-share deviation and max–min spread.

Utilization

Module and plant utilization use rated current and optional target loading for normal and N−1 planning checks.

Efficiency

When AC input power is provided, estimate overall conversion efficiency from measured DC bus power.

FAQ and engineering references

What does rectifier load sharing mean?

Parallel rectifier modules should share DC load closely enough that no single healthy module is persistently overloaded or materially under-contributing. The acceptable tolerance must ultimately follow the power-system manufacturer specification.

How is load-sharing deviation calculated?

The analyzer compares each measured module current with the mean current of all online modules. The maximum absolute percentage deviation and the max-to-min spread are both reported.

Can low current prove a rectifier module is faulty?

No. A low-output module is a diagnostic signal, not a fault verdict. Check module alarms, current-limit settings, bus-voltage calibration, connectors, controller behavior and manufacturer diagnostics.

How is DC plant efficiency calculated?

When measured AC input power is provided, efficiency is DC output power divided by measured AC input power. DC output power is estimated from bus voltage multiplied by the sum of measured module currents.

What does the recommended online-module count mean?

It is a planning estimate that considers present load, module rating, the selected redundancy reserve and the target per-module loading. Site policy and manufacturer efficiency curves remain authoritative.
