# DC Plant Efficiency & Rectifier Load-Sharing Analyzer — Engineering Method

Version: V2.1-Tool30
Modified: 2026-09-10

## Managed quantities
- Per-module measured DC current
- Mean current and signed deviation from mean
- Maximum absolute sharing deviation and current spread
- Module rated loading
- DC output power = DC bus voltage × total module current
- Measured conversion efficiency = DC output / measured AC input
- N/N+1/N+2 survival capacity
- Target-loading online-module planning

## Safety boundary
The warning thresholds are screening assumptions. A low-current module is not automatically faulty. Confirm alarms, controller settings, calibration, wiring and manufacturer specifications.
