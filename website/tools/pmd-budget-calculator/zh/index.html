偏振模色散（PMD）预算计算器

偏振模色散（PMD）使脉冲的两个偏振模到达时间略有差异。与色散不同，PMD 随长度的平方根增长：按 0.20 ps/√km 设计的 G.652.D 链路，80 km 平均 DGD 约 1.8 ps。本 PMD 预算计算器把光纤与器件 DGD 合成，对比码元周期容限并求 PMD 受限距离。

计算方法

计算方法与工程说明

使用方法

  1. 输入 PMD 系数（光缆 PMDQ 链路设计值）和光纤长度。
  2. 填写放大器、DCM 等器件数量和单个平均 DGD。
  3. 输入码元速率，以及允许平均 DGD 占码元周期的百分比。
  4. 查看平均 DGD、余量和 PMD 受限距离。

DGD 公式

光纤平均 DGD = PMD 系数 × √L（ps），因为 PMD 按随机游走累积。相互独立的段按平方和合成：总 DGD = √(光纤² + Σ 器件²)。码元周期 = 1000 / 码元速率（GBd），单位 ps；允许平均 DGD = 码元周期 × 所选百分比。

受限距离

PMD 受限距离 = (允许值² − Σ 器件²) / PMD²。瞬时 DGD 服从麦克斯韦分布，设计最大值通常取平均值约 3 倍。80% 预警阈值是本工具的筛查规则。

算例：10.3125 GBd、80 km

0.20 ps/√km × √80 = 1.789 ps。4 个 0.1 ps 器件增加 0.04 ps²，平均 DGD 1.800 ps。码元周期 96.97 ps，10% 允许值 9.70 ps，余量 7.897 ps（占用 18.6%）。设计最大值约 5.40 ps，PMD 受限距离约 2,350 km。

常见问题

常见问题

如何计算光纤链路的 PMD？

平均 DGD = PMD 系数 × √长度。0.20 ps/√km、80 km 为 0.2 × 8.94 = 1.79 ps，器件 DGD 按平方和叠加。

10G 的 PMD 限值是多少？

按码元周期 10% 的常用规则，10.3125 GBd 允许平均 DGD 约 9.7 ps。0.5 ps/√km 的老光纤约 376 km 就会达到。

为什么 PMD 随长度平方根增长？

光纤双折射沿长度随机变化，时延按随机游走累积，因此与 √L 成正比。

PMD 和 DGD 有什么区别？

DGD 是两个偏振模之间的瞬时时延；PMD 是 DGD 在波长和时间上的平均值，PMD 系数是每 √km 的平均值。

相干 100G/400G 还要关注 PMD 吗？

影响小得多。相干 DSP 可补偿数十 ps 的 DGD，限制 10G NRZ 的老光纤仍可承载相干信号。
