About and applicability

Use this to budget ASE for identical optical amplifiers that restore the channel to the same output power. The noise factor F is 10^(NF_dB/10) and multiplies h·f·(G−1)·B. It is not a measured OSNR and it leaves out nonlinear interference, filter narrowing and polarization details.

This is an engineering approximation for planning. It is not a laboratory measurement and it does not guarantee equipment performance.

Content reviewed: 2026-11-19

How it is calculated

P_ASE = N × F × h × f × (G − 1) × B; OSNR = P_channel / P_ASE.

Planck's constant is the exact SI value 6.62607015×10^−34 J·s. Linear gain G and linear noise factor F come from the decibel inputs. ASE of one amplifier in bandwidth B is F·h·f·(G−1)·B. N identical spans add those ASE powers. OSNR is channel power divided by that total, reported in decibels. Gain must be above 0 dB because this form uses (G−1). If your noise-figure definition already folds in a high-gain approximation, keep the same definition when you read the result.

FAQ

Is this the OSNR a meter would show?

No. A meter includes the real spectrum, filters and noise outside this model.

Why reject 0 dB gain?

G−1 is zero at unity gain, so this ASE expression does not apply.

Do spans have to be identical?

Yes. Different gains or noise figures need a span-by-span sum this page does not do.

Which bandwidth should I enter?

Use the reference bandwidth you want the OSNR quoted in, often 12.5 GHz for a 0.1 nm class reference.
