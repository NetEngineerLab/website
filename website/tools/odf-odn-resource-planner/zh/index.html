方法与边界

资源模型按目标 ONU、有效分光上限、保护系数和纤芯预留率计算需求，再向上组合标准光缆芯数。最不利光损仅作为资源方案门禁，3 dB 是本站规划阈值，不是标准强制值。

规划 BOM 不包含路由测绘、长度采购余量、厂商料号或报价；ODF 与接续容量来自用户或厂商输入。

常见问题

PON 端口数量如何计算？

目标 ONU 数除以总分光比与运营上限中的较小值，再向上取整。

如何计算纤芯预留？

工作纤芯除以一减预留率并向上取整，再组合一个或多个标准光缆芯数档位。

为什么方案会显示无法判定？

必要的拓扑、容量、损耗、距离或光接口参数缺失或无效。

规划 BOM 可以直接采购吗？

不可以。它不包含实测路由长度、施工余量、厂商料号和报价。

3 dB 警告阈值是标准强制值吗？

不是。这是 NetEngineerLab 的规划阈值，最终应按项目规则和设备规格书复核。
