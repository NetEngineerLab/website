Sobre e abrangência

Use isto para transformar uma taxa útil de MAC na taxa de linha mais alta indicada por um código de linha Ethernet publicado. Não escolhe um PMD, uma quantidade de vias nem um alcance.

Esta é uma aproximação de engenharia para planejamento. Não é uma medição de laboratório e não garante o desempenho do equipamento.

Revisado: 2026-11-19

Como o cálculo é feito

Taxa de linha = taxa útil × (bits de código / bits úteis). O RS-FEC multiplica uma razão extra de palavra-código.

8b/10b expande 8 bits úteis em 10 bits de linha, então a razão é 10/8. 64b/66b usa 66/64. RS(528,514) acrescenta 528/514 sobre 64b/66b. RS(544,514) acrescenta 544/514 sobre 64b/66b. Uma taxa útil de 10 Gbps com 64b/66b é exatamente 10.3125 Gbps. A calculadora aplica só essa razão. Autonegociação, marcadores de alinhamento e o mapeamento de vias de uma cláusula ficam fora do resultado.

Perguntas

10.3125 Gbps é uma taxa medida?

É a expansão exata 66/64 de 10 Gbps.

O RS-FEC substitui 64b/66b?

Não. As predefinições multiplicam as duas razões.

Posso colar isto num switch como uma velocidade?

Não. É a aritmética da taxa de linha do código selecionado.

De onde vêm as razões?

São os tamanhos publicados de 8b/10b, 64b/66b, RS(528,514) e RS(544,514) usados pelo IEEE 802.3.
