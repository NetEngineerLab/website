    METODOLOGÍA

    Metodología

    TCP MSS

    RFC 6691 recomienda restar solo las cabeceras IP y TCP fijas al anunciar el MSS. La herramienta calcula por separado los datos reales después de las opciones configuradas.

    PPPoE

    RFC 2516 usa 6 bytes para la cabecera PPPoE y 2 bytes para el campo de protocolo PPP, produciendo la conocida MTU de 1492 bytes sobre una carga Ethernet de 1500 bytes.

    VLAN y MPLS

    Una etiqueta VLAN ocupa 4 bytes en el cable. Cada entrada de la pila MPLS ocupa 4 bytes. VLAN normalmente no reduce la MTU IP configurada cuando se admite la expansión de tramas etiquetadas.

    Túneles y seguridad

    La sobrecarga de GRE, VXLAN, IPsec y WireGuard depende de la versión IP exterior y de los campos opcionales. El relleno IPsec es variable, por lo que sus preajustes son estimaciones editables.

    Referencias principales: RFC 2516 · RFC 6691 · RFC 2784 · RFC 2890 · RFC 7348 · RFC 3032 · RFC 4303 · RFC 8200 · RFC 8201 · WireGuard Protocol

    FAQ

    Preguntas frecuentes

    ¿Por qué la MTU de PPPoE suele ser 1492?

    Una carga Ethernet de 1500 bytes menos 8 bytes de sobrecarga PPPoE y del protocolo PPP deja 1492 bytes.

    ¿VLAN siempre debe reducir la MTU IP en 4 bytes?

    No. La mayoría de dispositivos Ethernet admiten la trama etiquetada ligeramente mayor y mantienen la MTU IP en 1500. Use el modo estricto solo cuando el límite físico de trama no se amplíe.

    ¿Por qué los valores de IPsec son estimaciones?

    La sobrecarga ESP depende de IP exterior, NAT-T, IV, etiqueta de integridad y relleno variable. Verifique el conjunto de cifrado y la implementación del proveedor.

    ¿Cuál es el MSS TCP correcto para una MTU IPv6 de 1500?

    Con solo cabeceras fijas, 1500 - cabecera IPv6 de 40 bytes - cabecera TCP de 20 bytes = 1440 bytes.

    ¿Ping puede demostrar la MTU completa de la ruta?

    Es útil, pero no concluyente. El filtrado ICMP, ECMP, los túneles y el enrutamiento asimétrico pueden afectar el resultado. Combínelo con PMTUD, capturas y contadores de dispositivos.

    ¿Qué significa una MTU IPv6 inferior a 1280?

    IPv6 define 1280 bytes como MTU mínima del enlace. Los diseños inferiores requieren fragmentación/reensamblaje en capas inferiores o adaptación y deben revisarse.
