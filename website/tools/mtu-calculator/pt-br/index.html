Cálculo do núcleo

Effective inner MTU = Underlay MTU − Σ(encapsulation overhead). TCP MSS ≈ Effective MTU − IP header − TCP header (− options). Fragmentation risk when Desired inner MTU > Effective MTU.

Pilha overhead. Sum VLAN, tunel e cabeçalhos L3/L4 que ficam fora do pacote interno.

MTU eficaz. O que resta para o pacote IP interno depois de underlay MTU paga por cada byte externo.

MSS. Anuncie MSS para que a carga útil TCP se ajuste sem fragmentação IP neste caminho.

Fragmentação. Se o MTU interno desejado exceder o valor efetivo, encolher MSS ou aumentar o MTU underlay.

    Metodologia

    METODOLOGIA

    TCP MSS

    RFC 6691 recomenda subtrair Cooperativamente apenas os cabeçalhos fixos IP e TCP ao anunciar MSS. A ferramenta calcula separadamente os dados reais após as opções configuradas.

    PPPoE

    RFC 2516 usa 6 bytes para o cabeçalho PPPoE e 2 bytes para o campo de protocolo PPP, produzindo o familiar 1492-byte MTU numa carga Ethernet de 1500 bytes.

    VLAN e MPLS

    Uma etiqueta VLAN é de 4 bytes no fio. Cada entrada de pilha de etiquetas MPLS é de 4 bytes. O VLAN normalmente não reduz o IP configurado MTU quando é suportada a expansão de quadros marcados.

    Túneis e segurança

    GRE, VXLAN, IPsec e WireGuard acimahon depende da versão IP externa e campos opcionais. O enchimento IPsec é variável, então suas predefinições são estimativas editáveis.

    Referências primárias: RFC 2516 · RFC 6691 · RFC 2784 · RFC 2890 · RFC 7348 · RFC 3032 · RFC 4303 · RFC 8200 · RFC 8201 · Protocolo WireGuard

    Perguntas mais frequentes

    FAQ

    Porque é que o PPPoE MTU normalmente é 1492?

    - Não.

    O VLAN deve sempre reduzir o IP MTU em 4 bytes?

    Não. Os dispositivos Ethernet mais capazes suportam o quadro marcado ligeiramente maior, mantendo o IP MTU em 1500. Use o modo estrito apenas quando o limite de quadros físicos não se expandir.

    Por que os valores IPsec são estimados?

    A sobrecarga de ESP depende de IP externo, NAT-T, IV, etiqueta de integridade e enchimento variável. Verifique o pacote de cifras e a implementação do fornecedor.

    Qual é o TCP correto MSS para IPv6 MTU 1500?

    Apenas com cabeçalhos fixos, 1500 - 40-byte IPv6 header - 20-byte TCP header = 1440 bytes.

    O ping pode provar o caminho completo MTU?

    É útil, mas não conclusivo. Filtragem ICMP, ECMP, túneis e roteamento assimétrico podem afetar o resultado. Combine-o com PMTUD, capturas e contadores de dispositivos.

    O que significa IPv6 MTU abaixo de 1280?

    IPv6 define 1280 bytes como o link mínimo MTU. Desenhos abaixo que exigem fragmentação/remontagem ou adaptação de camadas inferiores e devem ser revistos.
