About and applicability

Use this when a DWDM plan names channels as an integer offset from 193.1 THz. The wavelength is the vacuum wavelength of that frequency. It does not include the effective group index of fiber, a transceiver's wavelength tolerance, or a vendor channel map.

This is an engineering approximation for planning. It is not a laboratory measurement and it does not guarantee equipment performance.

Content reviewed: 2026-11-19

How it is calculated

f = f_anchor + n × spacing; λ = c / f, with c = 299792458 m/s.

ITU-T G.694.1 anchors the DWDM frequency grid at 193.1 THz. A channel index n and a spacing in hertz give f = 193.1 THz + n × spacing. The vacuum wavelength follows λ = c / f. The speed of light used here is the exact SI value 299792458 m/s, so λ in nanometres is 299792.458 / f in terahertz. Neighboring rows use the same spacing. Changing the anchor is allowed for a what-if study; the published grid anchor remains 193.1 THz.

FAQ

Is 1550 nm exactly channel 0?

No. Channel 0 at 193.1 THz has a vacuum wavelength of 299792.458 / 193.1 nanometres, about 1552.52 nm.

Does a negative index go to a longer wavelength?

Yes. A lower frequency is a longer vacuum wavelength.

Can this replace a transceiver datasheet?

No. It only converts the grid definition you enter.

Why is the spacing not fixed at 100 GHz?

G.694.1 also defines other spacings. The spacing is an input.
