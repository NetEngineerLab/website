关于与适用范围

波分方案用相对 193.1 THz 的整数序号称呼信道时，用本页换算。波长是该频率的真空波长，不含光纤群折射率、光模块波长容差或厂商信道表。

这是规划用的工程近似，不是实验室实测，也不保证设备实际性能。

内容复核：2026年11月19日

计算方法

f = f_anchor + n × spacing; λ = c / f, with c = 299792458 m/s.

ITU-T G.694.1 把 DWDM 频率栅格锚在 193.1 THz。信道序号 n 和以赫兹计的间隔给出 f = 193.1 THz + n × 间隔。真空波长为 λ = c / f。这里的光速是国际单位制的精确值 299792458 m/s，因此以纳米计的波长等于 299792.458 除以以太赫兹计的频率。相邻行使用同一间隔。锚点可以改做假设分析，已发布栅格的锚点仍是 193.1 THz。

问答

1550 nm 是不是正好 0 号信道？

不是。193.1 THz 的 0 号信道真空波长是 299792.458 / 193.1 纳米，大约 1552.52 nm。

负序号是不是更长的波长？

是。更低的频率对应更长的真空波长。

它能代替光模块手册吗？

不能。它只换算你输入的栅格定义。

间隔为什么不固定成 100 GHz？

G.694.1 还定义了其他间隔。间隔是输入。
