工程提示

    点对点无线链路预算与可靠性规划

    本计算器适用于 2.4、5、6、11、24 或 60 GHz 视距链路前期规划，把无线电功率、馈线与天线参数同自由空间损耗、手动附加损耗和单点第一菲涅耳区检查结合起来。

    EIRP、FSPL 与接收电平

    EIRP 等于发射功率减发射馈线损耗再加发射天线增益；引擎随后扣除自由空间路径损耗、手动附加损耗和接收馈线损耗，并加入接收天线增益。

    Pr = Pt − Ltx + Gtx − FSPL − Lextra + Grx − Lrx

    FSPL 只描述无遮挡自由空间，不是完整的地形、绕射、降雨、气体、植被或干扰模型。

    衰落余量与目标可用率

    衰落余量等于接收电平减所填接收灵敏度。10 dB 与 20 dB 状态区间只是规划筛选值；所需余量取决于目标调制、可用率、地理气候、多径和降水统计。

    菲涅耳区净空与路径剖面

    工具只在一个障碍物位置计算第一菲涅耳区半径，并把实际净空与该半径的 60% 比较。路径勘测仍需覆盖全程地形、地球曲率、折射、建筑物和植被增长。

    高频附加损耗与法规核对

    许多微波和毫米波链路必须考虑雨衰与大气气体吸收；接近 60 GHz 时，氧气吸收需手动计入附加损耗。计算所得 EIRP 不是合规结论，仍要核对当地频段、功率、天线和许可规则。

    无线链路预算常见问题

    点对点无线链路需要多少衰落余量？

    不存在通用固定值。应根据目标可用率、频率、距离、气候、地形以及目标调制与吞吐量对应的接收门槛确定。页面的 10 dB 和 20 dB 状态只是筛选门槛，不是可用率保证。

    附加损耗会自动计算雨衰、氧气吸收或植被损耗吗？

    不会。该字段是手动合并余量。应使用适用模型或测量估算降雨、气体、植被、天线罩、极化、对准及其他损耗，再把合计值填入。

    EIRP 结果能证明无线设备合法可用吗？

    不能。本工具只用发射功率加天线增益并扣除发射端损耗。每个地区和链路端点仍需核对频段、信道、带宽、天线规则、许可及 EIRP 或功率限制。

    第一菲涅耳区保持 60% 净空就能证明整条路径畅通吗？

    不能。半径只在所填障碍物位置计算。完整路径剖面还必须覆盖全程地形、建筑物、未来植被、地球曲率和大气折射。

    接收灵敏度应该填写哪个数值？

    应采用目标调制方式、编码率、信道带宽和持续吞吐量对应的厂商门槛，而不是只选最低速率下最灵敏的数值；现场还要核对极化、天线对准与干扰。
