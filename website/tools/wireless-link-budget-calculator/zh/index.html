工程提示

    计算方法

    接收电平

    先计算EIRP，再扣除自由空间路径损耗、附加损耗与接收端馈线损耗，并加入接收天线增益。

    Pr = Pt − Ltx + Gtx − FSPL − Lextra + Grx − Lrx

    菲涅尔区净空

    工程上通常至少保持第一菲涅尔区60%净空；地形、树木和建筑物仍需现场勘测。

    常见问题

    衰落余量多少合适？

    一般链路至少保留10 dB，重要或气候恶劣链路常需20 dB以上，并结合降雨、植被和可靠性目标调整。

    这个结果能替代现场勘测吗？

    不能。还需核对法规EIRP限制、地形剖面、雨衰、极化、设备调制速率和厂商规格。
