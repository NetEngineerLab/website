METODOLOGIA

Metodologia e notas de engenharia

Orçamento ODN padrão

Potência mínima de transmissão menos sensibilidade do receptor menos penalização óptica. GPON B+ permite até 28 perda dBteria ODN, enquanto C+ permite até 32 dB.

Perda física de ODN

Perda de fibra + perda de splice + perda de conector + perda de divisor multi-estágio + outra perda passiva.

Perda total do projeto ODN

Perda física de ODN + margem de engenharia. A margem abrange envelhecimento, temperatura, conexões de manutenção e variação de medição.

Potência de recepção estimada

Potência mínima de transmissão menos perda física de ODN. Pena de caminho óptico e margem de engenharia são termos de orçamento, não apresentam perdas de componentes físicos.

Exemplos de normas por-- que

GPON Referência C+ a jusante: +3 dBm potência mínima de transmissão, −30 dBm ONU sensibilidade, - 8 dBm sobrecarga e 1 dB penalização do caminho óptico; 10 km a 1490 nm, primário 1:8 mais secundário 1:8, 6 splices, 4 conectores e 3 dB margem de engenharia.

ITU-T define classes ópticas do sistema e ODN Intervalos de perdas. Para XGS-PON (ITU-T G.9807.1), entrar potência de transmissão, sensibilidade do receptor, limiar de sobrecarga e penalização óptica do equipamento implantado; esta ferramenta não tem predefinição XGS e não deve inferir valores XGS de GPON B+/C+. Suposições de splice, conector e atenuação de fibra ainda devem ser ajustadas às regras da empresa, especificações de componentes e dados de campo.

Verificação por componente

Perda física de ODN = atenuação de fibra × comprimento + perda de divisor + perda de conector + perda de vassoura + outra perda passiva. Para o caso padrão: 3,0 dB fibra + 21,0 dB divisores + 1,2 dB conectores + 0,6 dB splices = 25,8 dB perda física ODN, eo 3 dB margem de engenharia traz perda de design para 28,8 dB. O 1 UnitsdB path penality não é adicionado à perda; é deduzido do orçamento: +3 dBm - (−30 dBm) - 1 dB = 32 dB padrão ODN orçamento, deixando 3,2 dB restante (90% do orçamento usado). A potência mínima de transmissão +3 dBm, portanto, prediz -22,8 dBm receber potência, 7,2 dB acima da sensibilidade; na potência máxima de transmissão +7 dBm o receptor permanece 10,8 dB abaixo do limite de sobrecarga −8 dBm. O margem de engenharia não é deduzido do poder de recepção.

As etiquetas GPON B+ (28 dB) e C+ (32 dB) são classes de referência do perfil de padrões selecionado, não uma garantia para cada par OLT/ONU. Confirme a sensibilidade real do transmissor, receptor, sobrecarga, comprimento de onda e classe ODN na ficha de dados do equipamento. Continuar a perda de fibra para contabilidade de rota ou PON e cubo de tópico óptico para o fluxo de trabalho de projeto.

FAQ

Perguntas mais frequentes

Por que o padrão muda para GPON C+ quando 1:8 × 1:8 é retido?

Uma cascata 1:8 × 1:8 contribui com cerca de 21 dB de perda de divisor. Com 10 km de fibra, conectores e emendas, a perda física do ODN é de 25.8 dB; adicionar o 3 dB margem de engenharia dá uma perda ODN projeto de 28.8 dB. Isso está acima do limite de 28 dB B+, mas dentro do orçamento 32 dB C+ (33 dB transmit-to-sensitive window menos 1 dB ótico caminho penal), deixando 3.2 dB.

Como um orçamento de energia difere do perda de fibra?

As perdas de fibra medem as perdas de rota e componentes. Porquê usar a potência mínima de transmissão?

Os projetos são verificados nas piores condições para evitar um resultado otimista causado pela variação do equipamento, envelhecimento e temperatura.

O poder de recebimento superior é sempre melhor?

Não. Valid A baixa potência pode cair abaixo da sensibilidade, enquanto a potência excessiva pode exceder o limite de sobrecarga. Receber energia deve permanecer dentro da janela permitida.

Por que margem de engenharia não é deduzido do poder de recepção?

A margem de engenharia é uma reserva de design, não uma perda física atual. É usado para verificação de orçamento enquanto receber energia usa perda física.

Por que a distância máxima é apenas uma estimativa?

A distância real também depende do tipo de cabo, temperatura, qualidade de splice, parâmetros de rota e equipamento.

Este resultado pode ser usado para a aceitação final?

A ferramenta suporta planejamento e solução de problemas. A aceitação final deve usar o medidor de potência e medições OTDR, especificações e padrões empresariais.

EVIDÊNCIA DE ENGENHARIA

Correcção da janela eléctrica e referências oficiais

A potência mínima de transmissão é utilizada para verificação da sensibilidade e do orçamento de perda. A potência máxima de transmissão é verificada separadamente contra a sobrecarga do receptor; usando apenas o valor mínimo pode esconder um risco de sobrecarga de ligação curta. Predefinições são referências de planejamento, não substitutos para o OLT/ONU exato ou planilha de dados do transceptor. O limite 3 dB Saudável/Cuidado é o limiar de planejamento dessa ferramenta, não um mandato universal de normas.

Base de fórmula
Orçamento ODN padrão = mínimo Tx − sensibilidade do receptor − penalidade do caminho óptico. Perda física ODN = fibra + splicengel + conector + divisor + outra perda passiva. Perda de projeto = perda física + margem de engenharia. Estima-se que a potência de recepção utiliza apenas perda física. Os limites de classe GPON B+/C+ seguem as gamas de Hydroplaining ITU-T G.984.2 citadas nesta página.
Limites de aplicabilidade
Planeamento e solução de problemas para orçamentos de ligação óptica / PON. Predefinições são classes de referência, não uma garantia para cada par OLT/ONU. Não é um substituto para o medidor de potência ou aceitação OTDR, valores de planilha de dados ou padrões empresariais. Sem predefinição XGS-PON; digite valores de equipamento para projetos G.9807.1.
