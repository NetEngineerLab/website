METHODOLOGY

计算方法与工程说明

标准ODN预算

最小发送光功率 − 接收灵敏度 − 系统光学代价。GPON B+最大ODN损耗为28 dB，C+为32 dB。

物理ODN损耗

光纤损耗 + 熔接损耗 + 连接器损耗 + 多级分光器损耗 + 其他无源损耗。

总设计ODN损耗

物理ODN损耗 + 工程余量。工程余量用于覆盖老化、温度变化、维护连接和测量偏差。

预计接收光功率

最小发送光功率 − 物理ODN损耗。光学代价和工程余量属于预算项，不作为当前实际器件损耗扣除。

默认标准示例

GPON C+下行参考：最小发送功率+3 dBm、ONU接收灵敏度−30 dBm、过载门限−8 dBm、光学代价1 dB；10 km、1490 nm、一级1:8加二级1:8、6个熔接点、4个连接器、3 dB工程余量。

ITU-T定义的是系统光功率等级和ODN损耗范围；XGS-PON（ITU-T G.9807.1）的发送功率、接收灵敏度、过载门限和光学代价必须按实际设备规格输入，本工具不提供XGS预设，也不应从GPON B+/C+参数推导。熔接、连接器和光纤衰减值仍应按企业标准、器件规格和现场数据调整。

逐项核对工程案例

物理ODN损耗 = 光纤衰减 × 长度 + 分光器损耗 + 连接器损耗 + 熔接损耗 + 其他无源损耗。默认案例为：3.0 dB光纤 + 21.0 dB分光器 + 1.2 dB连接器 + 0.6 dB熔接 = 25.8 dB物理ODN损耗，加上3 dB工程余量后设计损耗为28.8 dB。1 dB光学代价不计入损耗，而是从预算中扣除：+3 dBm − (−30 dBm) − 1 dB = 32 dB标准ODN预算，剩余3.2 dB（预算使用90%）。因此+3 dBm最小发送功率预计得到−22.8 dBm接收光功率，比接收灵敏度高7.2 dB；按+7 dBm最大发送功率计算，距−8 dBm过载门限还有10.8 dB。工程余量不作为当前物理损耗从接收光功率中扣除。

GPON B+（28 dB）与C+（32 dB）是所选标准配置的参考等级，不代表所有OLT/ONU组合都适用。应核对设备规格中的发送功率、接收灵敏度、过载门限、波长和ODN等级。可继续查看光纤链路损耗或PON与光网络专题。

FAQ

常见问题

为什么保留1:8×1:8后默认改为GPON C+？

1:8×1:8的分光器标称损耗约21 dB，再叠加10 km光纤、连接器和熔接点，物理ODN损耗为25.8 dB；加上3 dB工程余量后，设计ODN损耗为28.8 dB。这超过B+的28 dB上限，但在C+的32 dB预算以内（33 dB收发功率窗口减去1 dB光学代价），剩余3.2 dB。

光功率预算和光纤链路损耗有什么区别？

光纤链路损耗关注线路和器件造成了多少损耗；光功率预算还结合发送功率、接收灵敏度和过载门限，判断设备能否可靠工作。

为什么应使用最小发送光功率？

工程设计通常按最不利条件校核，以避免设备差异、老化和温度变化导致预算过于乐观。

接收光功率越高越好吗？

不是。接收功率过低会低于灵敏度，过高则可能超过过载门限，应位于接收机允许窗口内并保留余量。

工程余量为什么不从预计接收功率中扣除？

工程余量是设计储备，不是当前实际器件损耗，因此用于预算判断，但预计接收功率按物理损耗计算。

最大距离为什么只是估算值？

实际距离还受光缆类型、温度、熔接质量、路由和设备参数影响。

结果能否直接用于验收？

本工具适合规划、复核和故障分析；正式验收应结合光功率计、OTDR、设备规格和企业标准。
