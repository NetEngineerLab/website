关于与适用范围

面向通信与网络工程师的免费规划计算器。全部在浏览器中运行：输入 OLT/ONU 功率窗口和 ODN 损耗，估算等级预算剩余、接收光功率、灵敏度余量、过载余量和最大距离。应用类别：工程工具 / 光链路设计。无需账号。

用于 GPON/EPON 的 ODN 规划、接收窗口校核和排障。结果是规划辅助，不能替代设备规格书、光功率计或 OTDR 验收，也不能替代企业规范。

计算方法 · 公式
等级预算 = Tx_min − 接收灵敏度 − 光学代价
物理损耗 = 光纤 + 熔接 + 连接器 + 分光器 + 其他
设计损耗 = 物理损耗 + 工程余量
剩余 = 等级预算 − 设计损耗
接收光功率 = Tx_min − 物理损耗

光学代价和工程余量属于预算项，不是当前已经存在的器件损耗，因此接收光功率只扣物理损耗。区分理论等级预算、物理 ODN 损耗和工程余量，才能正确理解健康 / 风险 / 超限。

标准 ODN 预算

最小发送光功率 − 接收灵敏度 − 系统光学代价。GPON B+ 最大 ODN 损耗为 28 dB，C+ 为 32 dB（按 ITU-T G.984.2 等级范围作规划参考）。

物理 ODN 损耗

光纤损耗 + 熔接损耗 + 连接器损耗 + 多级分光器损耗 + 其他无源损耗（WDM、衰减器、配线架）。

总设计 ODN 损耗

物理 ODN 损耗 + 工程余量。工程余量用于覆盖老化、温度变化、维护连接和测量偏差。

预计接收光功率

最小发送光功率 − 物理 ODN 损耗。光学代价和工程余量属于预算项，不作为当前实际器件损耗扣除。

默认标准示例

GPON C+ 下行参考：最小发送功率 +3 dBm、ONU 接收灵敏度 −30 dBm、过载门限 −8 dBm、光学代价 1 dB；10 km、1490 nm、一级 1:8 加二级 1:8、6 个熔接点、4 个连接器、3 dB 工程余量。

ITU-T 定义的是系统光功率等级和 ODN 损耗范围。XGS-PON（ITU-T G.9807.1）的发送功率、接收灵敏度、过载门限和光学代价必须按实际设备规格输入。本工具不提供 XGS 预设，也不应从 GPON B+/C+ 参数推导。熔接、连接器和光纤衰减值仍应按企业标准、器件规格和现场数据调整。

状态规则 · 健康 / 风险 / 超限

结论取三项检查中最紧的一项：相对等级预算的剩余、高于接收灵敏度的余量，以及按最大发送功率计算的低于过载门限的余量。

健康三项均 ≥ 3 dB
风险任一项 0 ≤ x < 3 dB
超限任一项低于 0 dB

3 dB 的健康 / 风险分界是本工具的规划门槛，不是标准统一强制值。

分项核对 · 默认损耗分解

物理 ODN 损耗 = 光纤衰减 × 长度 + 分光器损耗 + 连接器损耗 + 熔接损耗 + 其他无源损耗。默认案例为：3.0 dB 光纤 + 21.0 dB 分光器 + 1.2 dB 连接器 + 0.6 dB 熔接 = 25.8 dB 物理 ODN 损耗，加上 3 dB 工程余量后设计损耗为 28.8 dB。1 dB 光学代价不计入损耗，而是从预算中扣除：+3 dBm − (−30 dBm) − 1 dB = 32 dB 标准 ODN 预算，剩余 3.2 dB（预算使用 90%）。因此 +3 dBm 最小发送功率预计得到 −22.8 dBm 接收光功率，比接收灵敏度高 7.2 dB；按 +7 dBm 最大发送功率计算，距 −8 dBm 过载门限还有 10.8 dB。工程余量不作为当前物理损耗从接收光功率中扣除。

GPON B+（28 dB）与 C+（32 dB）是所选标准配置的参考等级，不代表所有 OLT/ONU 组合都适用。应核对设备规格中的发送功率、接收灵敏度、过载门限、波长和 ODN 等级。可继续查看光纤链路损耗或PON 与光网络专题。

问答

常见问题

为什么保留 1:8 × 1:8 后默认改为 GPON C+？

1:8 × 1:8 的分光器标称损耗约 21 dB。再叠加 10 km 光纤、连接器和熔接点，物理 ODN 损耗为 25.8 dB；加上 3 dB 工程余量后，设计 ODN 损耗为 28.8 dB。这超过 B+ 的 28 dB 上限，但在 C+ 的 32 dB 预算以内（33 dB 收发功率窗口减去 1 dB 光学代价），剩余 3.2 dB。

光功率预算和光纤链路损耗有什么区别？

光纤链路损耗衡量线路和器件损耗。光功率预算还结合发送功率、接收灵敏度和过载门限，判断设备能否可靠工作。

为什么应使用最小发送光功率？

工程设计通常按最不利条件校核，以避免设备差异、老化和温度变化导致预算过于乐观。

接收光功率越高越好吗？

不是。接收功率过低会低于灵敏度，过高则可能超过过载门限，应位于接收机允许窗口内。

工程余量为什么不从预计接收功率中扣除？

工程余量是设计储备，不是当前实际器件损耗。它用于预算判断，而预计接收功率按物理损耗计算。

最大距离为什么只是估算值？

实际距离还受光缆类型、温度、熔接质量、路由和设备参数影响。

结果能否直接用于验收？

本工具适合规划、复核和故障分析。正式验收应结合光功率计、OTDR、设备规格和企业标准。
