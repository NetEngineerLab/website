About & applicability

Free planning calculator for telecom and network engineers. Runs entirely in the browser: enter OLT/ONU power windows and ODN losses to estimate class budget remaining, receive power, sensitivity margin, overload margin and maximum reach. Application category: engineering utility / optical link design. No account required.

Use for GPON/EPON ODN planning, receive-window checks and troubleshooting. Results are planning aids — not a substitute for datasheet values, power-meter or OTDR acceptance, or enterprise standards.

How it’s calculated · methods & formulas
class budget = Tx_min − Rx_sensitivity − path_penalty
physical loss = fiber + splices + connectors + splitters + other
design loss = physical loss + engineering margin
remaining = class budget − design loss
Rx = Tx_min − physical loss

Optical path penalty and engineering margin are budget terms, not present physical component losses, so receive power uses physical loss only. Distinguishing theoretical class budget, physical ODN loss and engineering margin is required for correct Pass / Marginal / Fail interpretation.

Standard ODN budget

Minimum transmit power minus receiver sensitivity minus optical path penalty. GPON B+ allows up to 28 dB ODN loss, while C+ allows up to 32 dB (ITU-T G.984.2 class ranges used as planning references).

Physical ODN loss

Fiber loss + splice loss + connector loss + multi-stage splitter loss + other passive loss (WDM, attenuators, patch panels).

Total design ODN loss

Physical ODN loss + engineering margin. The margin covers ageing, temperature, maintenance connections and measurement variation.

Estimated receive power

Minimum transmit power minus physical ODN loss. Optical path penalty and engineering margin are budget terms, not present physical component losses.

Default standards example

GPON C+ downstream reference: +3 dBm minimum transmit power, −30 dBm ONU sensitivity, −8 dBm overload and 1 dB optical path penalty; 10 km at 1490 nm, primary 1:8 plus secondary 1:8, 6 splices, 4 connectors and 3 dB engineering margin.

ITU-T defines system optical classes and ODN loss ranges. For XGS-PON (ITU-T G.9807.1), enter transmit power, receiver sensitivity, overload threshold and optical penalty from the deployed equipment; this tool has no XGS preset and must not infer XGS values from GPON B+/C+. Splice, connector and fiber attenuation assumptions must still be adjusted to enterprise rules, component specifications and field data.

Status rules · Pass / Marginal / Fail

The verdict takes the tightest of three checks: remaining class budget, margin above receiver sensitivity, and margin below overload (using maximum transmit power).

PassAll three ≥ 3 dB
MarginalAny check 0 ≤ x < 3 dB
FailAny check below 0 dB

The 3 dB Pass / Marginal boundary is this tool’s planning threshold, not a universal standards mandate.

Component check · default loss breakdown

Physical ODN loss = fiber attenuation × length + splitter loss + connector loss + splice loss + other passive loss. For the default case: 3.0 dB fiber + 21.0 dB splitters + 1.2 dB connectors + 0.6 dB splices = 25.8 dB physical ODN loss, and the 3 dB engineering margin brings design loss to 28.8 dB. The 1 dB optical path penalty is not added to the loss; it is deducted from the budget: +3 dBm − (−30 dBm) − 1 dB = 32 dB standard ODN budget, leaving 3.2 dB remaining (90% of the budget used). The +3 dBm minimum transmit power therefore predicts −22.8 dBm receive power, 7.2 dB above sensitivity; at the +7 dBm maximum transmit power the receiver stays 10.8 dB below the −8 dBm overload threshold. The engineering margin is not deducted from receive power.

GPON B+ (28 dB) and C+ (32 dB) labels are reference classes from the selected standards profile, not a guarantee for every OLT/ONU pair. Confirm the actual transmitter, receiver sensitivity, overload, wavelength and ODN class in the equipment datasheet. FAQ

Frequently asked questions

Why does the default change to GPON C+ when 1:8 × 1:8 is retained?

A 1:8 × 1:8 cascade contributes about 21 dB of splitter loss. With 10 km of fiber, connectors and splices, physical ODN loss is 25.8 dB; adding the 3 dB engineering margin gives a design ODN loss of 28.8 dB. That is above the 28 dB B+ limit but within the 32 dB C+ budget (33 dB transmit-to-sensitivity window minus the 1 dB optical path penalty), leaving 3.2 dB.

How does a power budget differ from fiber loss?

Fiber loss measures route and component losses. A power budget also combines transmit power, receiver sensitivity and overload limits to determine whether equipment can operate reliably.

Why use minimum transmit power?

Designs are checked under worst-case conditions to avoid an optimistic result caused by equipment variation, ageing and temperature.

Is higher receive power always better?

No. Low power can fall below sensitivity, while excessive power can exceed the overload limit. Receive power should remain inside the allowed window.

Why is engineering margin not deducted from receive power?

Engineering margin is a design reserve, not a current physical loss. It is used for budget verification while receive power uses physical loss.

Why is maximum distance only an estimate?

Actual distance also depends on cable type, temperature, splice quality, route and equipment parameters.

Can this result be used for final acceptance?

The tool supports planning and troubleshooting. Final acceptance should use power meter and OTDR measurements, specifications and enterprise standards.

Formula basis

Standard ODN budget = minimum Tx − receiver sensitivity − optical path penalty. Physical ODN loss = fiber + splice + connector + splitter + other passive loss. Design loss = physical loss + engineering margin. Estimated receive power uses physical loss only. GPON B+/C+ class limits follow ITU-T G.984.2 planning ranges cited on this page.

Applicability limits

Planning and troubleshooting aid for optical / PON link budgets. Presets are reference classes, not a guarantee for every OLT/ONU pair. Not a substitute for power-meter or OTDR acceptance, datasheet values, or enterprise standards. No XGS-PON preset; enter equipment values for G.9807.1 designs.
