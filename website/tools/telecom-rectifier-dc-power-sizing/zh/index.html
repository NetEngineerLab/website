Battery recharge current is intentionally included because the worst loading can occur after utility restoration.

工程方法

Required rectifier current = (site load + battery recharge current) × engineering headroom. The active module count is rounded up, then N+1/N+2 redundancy is added.

Final module loading, AC feeder and protection must follow the exact power-system manufacturer design limits.

常见问题与参考资料

为什么整流容量要计入电池回充电流？

市电恢复后，开关电源既要承担在线通信负载，又可能需要给蓄电池回充，因此回充阶段往往是直流系统的高负荷场景。

N+1和N+2冗余如何计算？

工具先根据通信负载、电池回充和工程余量向上取整得到工作模块数，再按策略增加1块或2块冗余模块。

掉一块模块校验是什么意思？

把设计所需电流与少一块整流模块后的剩余容量比较，用于判断单模块故障时是否仍能满足目标负载。

能直接用这个结果选择交流空开吗？

不能。交流输入估算只作为上游规划输入，最终保护器件还要核对厂家数据、导线载流量、短路电流、分断能力及当地电气规范。

这个工具能替代厂家开关电源设计吗？

不能。最终应核对控制器与机框容量、模块降额、电池回充策略、环境温度、布线接地以及具体厂家的冗余要求。
