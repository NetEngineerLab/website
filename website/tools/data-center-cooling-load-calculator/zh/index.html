常见问题与参考资料

为什么 IT 功耗可以近似看作 IT 发热量？

IT设备消耗的电能最终几乎都会在受控空间内转化为热，因此 IT kW 可作为显热负荷的一阶工程输入。

UPS和PDU损耗是否要计入？

如果这些损耗释放在机房受控空间内，就应该计入；如果热量在房间外排散，则不要重复计算。

制冷 N+1 如何计算？

先按设计显热负荷计算实际需要运行的空调台数，再增加1台冗余，并核验任意1台退出后的剩余容量。

是否包含湿度和潜热负荷？

本V1主要计算显热。加湿、除湿、渗透风等潜热负荷需要进一步进行湿空气过程设计。

能否替代精密空调厂家选型？

不能。最终应使用厂家在实际回风/送风条件、海拔、风量、冗余策略和现场气流组织下的显冷量进行选型。
