    Metodología
    OSPF cost is reference bandwidth divided by interface bandwidth, rounded to the selected integer mode and bounded to 1�?5535. A manual metric override is preserved and flagged for review. Path cost is the sum of active interface costs; paths with the same lowest cost are ECMP candidates.
    Validate reference bandwidth, vendor defaults, area policy, interface speed and adjacency state before production changes.
