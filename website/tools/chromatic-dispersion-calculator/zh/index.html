受限距离与展宽

限制

满足 |D × L − C| ≤ 容限 T 的长度位于 (C·sign(D) − T) / |D| 与 (C·sign(D) + T) / |D| 之间。无补偿时下限为 0，只显示最大长度；过补偿链路（例如 D = 17、C = 2,000、T = 400）会显示完整区间 94.12–141.18 km。脉冲展宽按 |残余色散| × Δλ 估算（ps）。80% 预警阈值是本工具的筛查规则，不是标准值。

计算方法与工程说明
D(λ) = (S₀ / 4) × (λ − λ₀⁴ / λ³); CD = D × L − C

计算方法

使用方法

  1. 保留 G.652 模型，或选择“厂家数据”并输入光缆规格书中的 D 值。
  2. 输入工作波长、光纤长度以及 DCM/FBG 补偿量。
  3. 输入光模块规格书给出的接收端色散容限。
  4. 查看残余色散、余量和色散受限距离。

色散公式

ITU-T G.652 给出色散系数 D(λ) = (S0/4)·(λ − λ0⁴/λ³) ps/(nm·km)，λ0 在 1300–1324 nm，S0 ≤ 0.092 ps/(nm²·km)。在 1550 nm、λ0 = 1310 nm、S0 = 0.092 时 D = 17.461 ps/(nm·km)。累积色散 = D × L；残余色散 = D × L − 补偿量。

算例

算例

算例：1550 nm、80 km

G.652 模型，λ0 1310 nm、S0 0.092：D = 17.461 ps/(nm·km)。80 km 累积 1,396.8 ps/nm。对 1,600 ps/nm 的接收端余量为 203.2 ps/nm（占用 87.3%，预警），色散受限距离 91.63 km。Δλ = 0.1 nm 时脉冲展宽 139.68 ps。加 680 ps/nm 补偿后残余 716.8 ps/nm。

常见问题

常见问题

G.652 光纤在 1550 nm 的色散是多少？

约 17 ps/(nm·km)。按 ITU-T G.652 模型取 λ0 = 1310 nm、S0 = 0.092，得到 17.46 ps/(nm·km)；实际光缆多在 16.5–18 之间。

如何计算累积色散？

色散系数乘以长度：CD = D × L。80 km × 17.46 ps/(nm·km) ≈ 1,397 ps/nm，再减去 DCM 或 FBG 补偿量即为残余色散。

10G 光模块的色散容限一般是多少？

取决于模块。直调 10G 模块常见约 800 ps/nm，10G ER/ZR 类常见约 1,600 ps/nm，请以规格书为准。

1310 nm 需要考虑色散吗？

影响很小。1310 nm 接近 G.652 光纤的零色散波长，D 接近 0。

相干光模块需要色散补偿吗？

通常不需要。相干接收机在 DSP 中电域补偿色散，可容忍数万 ps/nm。
