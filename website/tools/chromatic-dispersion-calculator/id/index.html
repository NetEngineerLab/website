Limits and broadening

Limits

Lengths that keep |D × L − C| within the tolerance T lie between (C·sign(D) − T) / |D| and (C·sign(D) + T) / |D|. Without compensation the lower bound is 0, so only the maximum is shown; an over-compensated link (for example D = 17, C = 2,000, T = 400) shows the full window 94.12–141.18 km. Pulse broadening is estimated as |residual CD| × Δλ in ps. The 80% warning threshold is this tool's screening rule, not a standard value.

Metode dan catatan teknis
D(λ) = (S₀ / 4) × (λ − λ₀⁴ / λ³); CD = D × L − C

METHODOLOGY

How to use

  1. Pertahankan model G.652, atau pilih “Nilai lembar data” dan masukkan D dari lembar data kabel.
  2. Masukkan panjang gelombang, panjang serat, dan kompensasi DCM atau FBG jika ada.
  3. Masukkan toleransi CD penerima dari lembar data transceiver.
  4. Baca CD sisa, margin, dan panjang yang dibatasi CD.

Dispersion formula

ITU-T G.652 menetapkan koefisien dispersi kromatik sebagai D(λ) = (S0/4)·(λ − λ0⁴/λ³) ps/(nm·km), dengan λ0 antara 1300 dan 1324 nm serta S0 ≤ 0,092 ps/(nm²·km). Pada 1550 nm dengan λ0 = 1310 nm dan S0 = 0,092, hasilnya 17,461 ps/(nm·km). CD terkumpul = D × L. CD sisa = D × L − kompensasi.

Worked examples

Worked examples

Worked case: 80 km at 1550 nm

Model G.652, λ0 1310 nm, S0 0,092: D = 17,461 ps/(nm·km). 80 km memberi 1.396,8 ps/nm. Terhadap penerima 1.600 ps/nm, marginnya 203,2 ps/nm (87,3% terpakai, peringatan) dan panjang yang dibatasi CD adalah 91,63 km. Dengan Δλ = 0,1 nm, pelembarannya 139,68 ps. Adding 680 ps/nm of compensation leaves 716.8 ps/nm residual.

Pertanyaan

FAQ

Berapa dispersi kromatik serat G.652 pada 1550 nm?

Sekitar 17 ps/(nm·km). Model ITU-T G.652 dengan λ0 = 1310 nm dan S0 = 0,092 memberi 17,46 ps/(nm·km). Kabel pada umumnya terukur 16,5–18.

Bagaimana menghitung dispersi kromatik total?

Kalikan koefisien dengan panjang: CD = D × L. 80 km × 17,46 ps/(nm·km) ≈ 1.397 ps/nm. Kurangi kompensasi DCM atau FBG untuk mendapat sisa.

Berapa toleransi CD yang umum untuk optik 10G?

Tergantung modul. Optik 10G termodulasi langsung sering disebut sekitar 800 ps/nm, sedangkan kelas 10G ER/ZR sering sekitar 1.600 ps/nm. Selalu pakai lembar data.

Apakah dispersi kromatik berarti pada 1310 nm?

Sangat kecil. 1310 nm dekat dengan panjang gelombang dispersi nol serat G.652, jadi D di sana mendekati 0.

Apakah optik koheren perlu kompensasi dispersi?

Biasanya tidak. Penerima koheren mengompensasi CD secara elektronik di DSP dan menoleransi puluhan ribu ps/nm.

ENGINEERING REFERENCES

  • ITU-T G.652 (08/2024): single-mode fibre and cable – §6.10 equation (6-1) chromatic dispersion coefficient D(λ) = (S0/4)(λ − λ0⁴/λ³); λ0 1300–1324 nm and S0 ≤ 0.092 ps/(nm²·km) in clause 8 Table 1 (G.652.B) and Table 2 (G.652.D)
  • ITU-T G.650.1 (01/2024): test methods for linear attributes – §6.5 chromatic dispersion measurement, Annex A fitting
  • ITU-T G.691 (03/2006): optical interfaces for single-channel STM-64 and other SDH systems with optical amplifiers – §6.3.2.1 maximum chromatic dispersion per application code
  • ITU-T G.655 (11/2009): non-zero dispersion-shifted fibre – use the datasheet D for these fibres
