关于与适用范围

这是 AWGN 容量上界。调制解调器、Wi-Fi MCS 表或光转发器都可能远低于它。信噪比可以按分贝或线性功率比输入。

这是规划用的工程近似，不是实验室实测，也不保证设备实际性能。

内容复核：2026年11月19日

计算方法

C = B × log2(1 + S/N).

香农 AWGN 公式是 C = B log2(1 + S/N)，B 是以赫兹计的带宽，S/N 是线性功率比。分贝信噪比 x 换成 10^(x/10)。一组可核算的例子是 B = 20 MHz、SNR = 20 dB，因此 S/N = 100，C = 20000000 × log2(101)。结果是你所输入带宽和信噪比下加性白高斯噪声的上界。它不是链路预算，也不包含衰落、干扰结构或协议开销。

问答

20 dB 的例子里有 log2(101) 吗？

有。20 dB 的线性比是 100，对数的自变量是 1+100。

信噪比可以是 0 dB 吗？

可以。线性比是 1，容量是每赫兹每秒 B 比特。

带宽更大是否一定更好？

只在这个公式里、并且你输入的信噪比仍然适用于那个更宽的带宽时才如此。

这是 Wi-Fi 吞吐吗？

不是。它是 AWGN 上界。
