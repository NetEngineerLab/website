Sobre e abrangência

Este é o limite de capacidade AWGN. Um modem, uma tabela MCS de Wi-Fi ou um transponder óptico pode ficar bem abaixo dele. A SNR pode ser informada em decibéis ou como razão linear de potência.

Esta é uma aproximação de engenharia para planejamento. Não é uma medição de laboratório e não garante o desempenho do equipamento.

Revisado: 2026-11-19

Como o cálculo é feito

C = B × log2(1 + S/N).

A fórmula AWGN de Shannon é C = B log2(1 + S/N). B é a largura de banda em hertz e S/N é uma razão linear de potência. Uma SNR de x decibéis vira 10^(x/10). Um caso conferível é B = 20 MHz e SNR = 20 dB: S/N = 100 e C = 20000000 × log2(101). O resultado é um limite superior para ruído gaussiano branco aditivo na largura de banda e na SNR informadas. Não é um orçamento de enlace e não inclui desvanecimento, estrutura de interferência nem sobrecarga de protocolo.

Perguntas

log2(101) faz parte do exemplo de 20 dB?

Sim. 20 dB é uma razão linear de 100, e o argumento do logaritmo é 1+100.

A SNR pode ser 0 dB?

Sim. A razão linear é 1 e a capacidade é B × 1 bit/s/Hz.

Uma banda mais larga sempre ajuda?

Só nesta fórmula, e só se a SNR informada ainda valer para essa banda mais larga.

Isto é uma vazão de Wi-Fi?

Não. É o limite AWGN.
