STP 路径开销计算器

生成树选择到根桥根路径开销最小的路径，根路径开销是沿途端口开销之和。IEEE 802.1D-2004 与 802.1Q 定义长开销方法：开销 = 20,000,000,000 ÷ 链路速率（kb/s），1 Gbps 为 20,000，10 Gbps 为 2,000；传统短开销 1 Gbps 为 4，10 Gbps 为 2。输入两条候选路径的链路速率，即可得到每个端口开销、合计以及 STP 转发的路径。

计算方法

计算方法与工程说明

使用方法

  1. 选择长开销（现代 RSTP/MSTP 默认）或传统短开销。
  2. 按跳列出路径 A 到根桥的链路速率（Mbps）。
  3. 同样填写路径 B。
  4. 比较根路径开销，总和较小者成为根端口所在路径。

长开销方法

IEEE 802.1D-2004 与 802.1Q 建议端口路径开销 = 20,000,000,000 ÷ 链路速率（kb/s），取值 1 到 200,000,000。结果：10 Mbps 2,000,000；100 Mbps 200,000；1 Gbps 20,000；10 Gbps 2,000；25 Gbps 800；40 Gbps 500；100 Gbps 200；400 Gbps 50。

短开销方法

IEEE 802.1D-1998 推荐的 16 位取值：4 Mbps 250、10 Mbps 100、16 Mbps 62、100 Mbps 19、1 Gbps 4、10 Gbps 2。该表未定义 10 Gbps 以上速率，本工具直接提示而不猜测厂家取值。

算例：两跳 10G 对比一跳 1G

长开销：路径 A = 2,000 + 2,000 = 4,000；路径 B = 20,000。尽管跳数更多，STP 仍以 16,000 的差值优选路径 A。若用短开销，两者均为 4（2 + 2 与 4），相同时由网桥 ID 决定——这也是 802.1D-2004 改用 32 位开销的原因之一。

常见问题

常见问题

STP 路径开销如何计算？

根路径开销是从本交换机到根桥沿途端口开销之和。长开销方法下每个端口开销 = 20,000,000,000 ÷ 链路速率（kb/s）。

10G 链路的 STP 开销是多少？

长开销（802.1D-2004/802.1Q）为 2,000，传统短开销为 2。

100G 的 STP 开销是多少？

长开销为 200。802.1D-1998 短开销表只到 10 Gbps，100G 没有标准短开销值。

IEEE 为什么改用长开销？

16 位短开销无法区分 10 Gbps 以上的链路，容易出现开销相同。32 位长开销可扩展到 10 Tb/s。

两条路径开销相同时怎么办？

STP 依次比较发送方网桥 ID 和发送方端口 ID，取较小者。
