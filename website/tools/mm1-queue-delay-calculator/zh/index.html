关于与适用范围

用于泊松到达、指数服务的单服务员队列。它不是交换机缓存模型，也不包含某个具体帧的串行化时间。

这是规划用的工程近似，不是实验室实测，也不保证设备实际性能。

内容复核：2026年11月19日

计算方法

ρ = λ / μ; E[T] = 1 / (μ − λ); E[W] = ρ / (μ (1 − ρ)).

M/M/1 队列的利用率是 ρ = λ/μ，只有 μ > λ 时队列稳定。平均逗留时间是 1/(μ−λ)。队列中的平均等待时间是 ρ/(μ(1−ρ))。系统内平均个数是 ρ/(1−ρ)，队列内平均个数是 ρ²/(1−ρ)。一组可手算的例子是每秒到达 800、每秒服务 1000：ρ = 0.8，逗留 5 ms，等待 4 ms。以每分钟输入的速率会先除以 60。

问答

到达率等于服务率会怎样？

模型不稳定。页面会拒绝。

5 ms 是实测吗？

不是。它是这组速率下的 1/200 秒。

每分钟速率会改变公式吗？

只改变单位换算。排队公式使用每秒速率。

能算多个服务员吗？

不能。这里只有一个服务员。
