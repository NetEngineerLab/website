    计算方法与工程边界

    收敛比怎么计算

    第1层比较 IT 侧线速与 Fabric 容量，第2层比较 Fabric 与上层容量，端到端比较 IT 侧线速与最终出口容量。

    Convergence = Downstream capacity / Upstream capacity

    东西向与南北向分开建模

    模型先拆分流量，再计算跨 Leaf/接入节点东西向业务对 Fabric 的两个链路穿越，并允许指定继续经过上层的比例。

    Spine N-1

    假设边缘上联均匀分散到中间层节点，故障后按剩余节点比例折减 Fabric 与上层容量。

    真实网络仍需遥测验证

    上线前应结合 P95/P99、队列丢包、ECMP/LAG 哈希分布、ASIC 转发能力和故障演练复核。

    FAQ

    什么是数据中心网络收敛比？

    它表示服务器或接入层向下提供的总容量，与下一层可用上联容量之间的比例。3:1 表示 3 份下联线速容量共享 1 份上联容量。

    收敛比和超售比是同一个概念吗？

    两者高度相关。超售比常描述单台交换机边界；收敛比更适合描述多层 Fabric 中容量逐层收敛的关系。

    Spine N-1 会如何影响容量？

    模型假设边缘上联均匀分布在 Spine 或汇聚节点上。故障一个中间层节点后，按其占比减少 Fabric 与上层容量。

    为什么跨 Leaf 的东西向流量按两次计算？

    跨 Leaf 流量既占用源 Leaf 的 Fabric 链路，也占用目的 Leaf 的 Fabric 链路，因此汇总 Fabric 端口承载量时计算两个链路穿越。

    这个工具能替代流量监控或 Fabric 仿真吗？

    不能。生产设计仍需结合 P95/P99、ECMP 分布、队列丢包、流量遥测、设备能力和故障演练复核。
