    计算方法 · 方法与公式
    PUE = 数据中心总能耗 ÷ IT 设备能耗（同一统计周期）
    非 IT 开销 = 总量 − IT
    目标设施能耗 ≈ IT × 目标 PUE
    规划节能量 ≈ 实测总量 − 目标设施能耗

    请在整个统计周期保持设施总能耗与 IT 能耗计量边界一致。状态颜色按你输入的目标 PUE 评估，不代表全球统一评级。仅在提供年度水耗或碳排放时计算 WUE/CUE。

    PUE 定义

    PUE 是同一统计周期内数据中心总能耗除以 IT 设备能耗。越接近 1，表示相对 IT 的设施开销越低。

    开销拆分

    制冷、UPS、照明、配电及其他负载解释与目标 PUE 的差距，并驱动构成条形图。

    成本影响

    用电单价把可避免的设施开销能耗换算为估算运行成本与目标 PUE 节能。

    计量边界

    不要把不足月的总量与完整周期 IT 能耗混用，也不要在未记录边界变化时直接跨站点比较。

    WUE / CUE

    可选的年度水耗与碳排放输入会在同一 IT 能耗基数上给出 WUE 与 CUE。

    结果为规划估算。投资决策前请核对表计标签、冗余方式与气候假设。

    问答

    常见问题

    PUE 应该采用什么计量边界？

    应在整个统计周期保持数据中心总能耗边界和 IT 能耗计量边界一致，并记录边界变化后再做跨期比较。

    瞬时功率可以计算 PUE 吗？

    可以用于运行快照；正式趋势和年度比较更适合采用完整周期的能耗数据。

    为什么 IT 负载上升后 PUE 可能下降？

    如果设施层固定开销变化不大，而有效 IT 负载提高，非 IT 开销被更多 IT 能耗分摊，PUE 可能下降。

    WUE 相比 PUE 多看了什么？

    WUE 衡量每单位 IT 能耗对应的运营用水量，可同时观察节能方案是否带来额外水资源影响。

    PUE 越低就一定越好吗？

    较低的设施开销通常更有利，但必须同时考虑可靠性、气候、冗余、业务负载以及计量边界。
