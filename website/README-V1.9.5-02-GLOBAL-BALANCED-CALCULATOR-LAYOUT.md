# NetEngineerLab V1.9.5-02

This hotfix completes the desktop two-column layout audit started in V1.9.4-01.

Affected tools:

- Optical Power Budget Calculator
- ONU Receive Power Calculator
- PON Distance Calculator
- PON Splitter Loss Calculator
- Fiber Loss Calculator

At desktop widths, the input and result cards now share the same height and the result modules use the available space evenly. Existing responsive breakpoints retain natural single-column layouts on smaller screens.

Calculation formulas, JavaScript, data, favicon/PWA assets, manifests, sitemap, and SEO metadata are unchanged.
