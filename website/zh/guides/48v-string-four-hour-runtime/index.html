600 W负载下，一组100Ah电池能撑住4小时吗？

这是工程示例，不是现场放电试验。24只电池、100Ah的一组在600 W下，本计算器的Peukert模型给出5.584小时，4小时目标可以通过。铭牌100Ah不能直接除以负载电流。

打开计算器 →

整流器指南解决模块容量，油机指南解决燃油。本例回答另一个问题：这组蓄电池本身能带多久的直流负载。

示例假设

  • 24只铅酸电池。标称2.0 V，起始2.1 V，截止1.75 V。一组，10小时率100 Ah。Peukert指数1.15。
  • 通路效率95%。放电深度80%。老化、温度和曲线系数都是100%。负载600 W，不再加余量。目标4小时。模型用Peukert。

步骤

  1. 标称母线48 V。起始50.4 V。截止42 V。平均电压46.2 V。
  2. 电池侧功率 = 600 / 0.95 = 631.58 W。平均电流 = 631.58 / 46.2 = 13.67 A。
  3. 可用容量 = 100 Ah × 0.80 = 80 Ah。简单估算是 80 / 13.67 = 5.852 小时。
  4. Peukert续航 = 5.584 小时。比4小时多1.584小时。同一目标需要74.82 Ah，所以这一组100 Ah仍然够用。

边界

这是计算器里的Peukert估算，不是厂家放电曲线。本表会提示放电率处于中等区间，并且电压下降时电流会上升。老化、低温或更低的截止电压都可能让4小时通不过，即使这张表通过了。不要把结果当成实测自治时间。
