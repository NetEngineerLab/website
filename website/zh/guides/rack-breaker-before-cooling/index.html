4 kW时机柜的16 A断路器会不会先于制冷失败？

这是工程示例，不是机柜验收。十台500 W设备按80%利用率是4000 W。230 V单相、16 A断路器上的电流是18.31 A，为断路器的114.4%。这些热量对应的制冷功率是1432.15 W，约1.222冷吨。

配套计算器

计算器没有可覆盖本例全部输入的网址预设。按下列数值手工输入后再对照结果。

打开计算器 →

制冷专题已经把房间热量换成冷吨。本例问的是一个机柜里谁先到限：输入的断路器，还是制冷功率。

示例假设

  • 十台设备，铭牌各500 W。利用率80%。没有增长，也没有额外冗余。功率因数0.95。230 V，单相，16 A断路器。
  • UPS效率0.95。PDU效率0.98。潜热份额为0。制冷COP为3。单路供电，不是双路。

步骤

  1. 实际功率 = 10 × 500 × 0.80 = 4000 W。视在功率 = 4000 / 0.95 = 4210.53 VA。
  2. 电流 = 4210.53 / 230 = 18.31 A。这是16 A的114.4%，计算器把电气校核标为不通过。
  3. 机柜发热 = 4000 / (0.95 × 0.98) = 4296.46 W。制冷输入 = 4296.46 / 3 = 1432.15 W，即1.222冷吨。

边界

80%警告线属于这个计算器。本例不通过，是因为18.31 A已经高于输入的16 A断路器，不是因为套用了某一条电气规范。冷吨不是房间的N+1设计。ASHRAE Datacom只作为热环境参考，不为本机柜出证。
