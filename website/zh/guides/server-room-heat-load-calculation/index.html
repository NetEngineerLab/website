服务器机房热负荷指南

服务器机房热负荷计算：应计入哪些热源？

先明确制冷边界，再建立热源清单，可以避免漏项和重复计入同一项电气损耗。

显热负荷精密空调N+1冷吨

快速结论

服务器机房热负荷等于受控边界内释放的各项热量之和。IT功率通常占比最大，但电能转换损耗、照明、人员、墙体、屋面、窗户、渗透风和辅助设备也可能需要计入。

先明确计算边界

先画出机房边界，再判断每一瓦损耗在哪里释放。UPS若位于机房外，其损耗可能由另一套系统承担；PDU变压器和电池若在机房内，则相关损耗可能属于本机房。边界清楚才能避免漏算和重复计算。

显热公式

基础负荷 = IT负荷 + UPS损耗 + PDU损耗 + 照明 + 人员 + 围护结构得热 + 其他显热

设计负荷 = 基础负荷 ×（1 + 工程余量）

120 kW完整实例

120 + 6 + 3 + 2 + 0.48 + 5 + 2 = 138.48 kW基础显热负荷。增加15%余量后，设计负荷为159.25 kW。其中非IT热量为18.48 kW；如果忽略房间和配电热量，基础负荷会低估约13.3%。

正确使用测量数据

已有机房优先使用实测IT功率，同时确认读数是瞬时值、峰值、计费周期值还是估算值。新建机房应建立可信的上架计划，不宜简单叠加所有设备铭牌功率。

显热与潜热

IT机房以显热为主，但室外空气渗透、人员和湿度控制会带来潜热。NetEngineerLab计算器用于显热规划；水分负荷明显时还需进行湿空气过程设计。

常见问题

服务器风扇需要单独计入吗？

风扇用电通常已经包含在实测IT功率中，最终也转化成热量，因此不应再次叠加。

能否把UPS额定容量当作UPS发热？

不能。应使用预期负载率下的转换损耗，并且只在损耗释放于制冷边界内时计入。

工程余量取多少合适？

应根据测量不确定性和增长计划给出有依据的数值。随意采用过大余量，可能导致长期低负载和控制效果变差。
