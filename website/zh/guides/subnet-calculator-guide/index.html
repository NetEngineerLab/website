Subnetting turns one IPv4 block into smaller broadcast domains. The reliable workflow is to read the prefix length, calculate the address count, then reserve network and broadcast addresses before assigning hosts.

总地址数 = 2^(32 − 前缀长度)
可用主机数 = 总地址数 − 2

计算示例: 192.168.10.0/24

/24 留出 8 个主机位，共有 256 个地址，范围为 192.168.10.0 至 192.168.10.255. 网络地址为 .0，广播地址为 .255，可用范围为 192.168.10.1–192.168.10.254.

实用子网划分工作流

  1. 用 32 减去前缀长度计算主机位。
  2. 确认网络边界和广播地址。
  3. 统计客户端容量前预留基础设施地址。
  4. 检查是否与现有路由重叠。

常见问题

/27 有多少个可用主机？
