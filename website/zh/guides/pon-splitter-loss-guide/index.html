本指南专门讨论PON分光器级联，不替代通用光纤链路预算记录。

总分光比等于各级分光比相乘；实际分光损耗等于各级标称插入损耗相加。ODN设计损耗还应计入光纤、熔接、连接器、光学代价和工程余量。

总分光比 = 各级分光比相乘
ODN设计损耗 = 分光器损耗 + 光纤损耗 + 熔接损耗 + 连接器损耗 + 光学代价 + 工程余量

可复算案例：10 km、1:8 × 1:8

总分光比 = 8 × 8 = 64（1:64），分光器损耗 = 10.5 + 10.5 = 21.0 dB。按0.30 dB/km计算，10 km光纤损耗为3.0 dB；6个熔接点为0.6 dB，4个连接器为1.2 dB，加入1 dB光学代价和3 dB工程余量后，设计损耗 = 29.8 dB。正式设计需替换为厂商规格和实测值。

校核步骤

  1. 用PON分光器损耗计算器确认级联比例和插入损耗。
  2. 用光纤链路损耗计算器拆分线路损耗。
  3. 用光功率预算计算器验证接收灵敏度和过载窗口。
  4. 现场使用光功率计与OTDR验收。

常见问题

多级级联能提高覆盖灵活性，但会增加连接点、插入损耗和维护复杂度；不能仅凭理论分光损耗批准设计。
