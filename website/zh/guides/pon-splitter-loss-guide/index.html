总分光比等于各级分光比相乘；实际分光损耗等于各级标称插入损耗相加。ODN设计损耗还应计入光纤、熔接、连接器损耗和工程余量；光学代价从功率预算中扣除。

总分光比 = 各级分光比相乘
ODN设计损耗 = 分光器损耗 + 光纤损耗 + 熔接损耗 + 连接器损耗 + 工程余量
可用预算 = 最小发送功率 − 接收灵敏度 − 光学代价

可复算的1:2至1:64分光损耗

理想均分损耗是 10 log10(N)。它只表示输入光功率被分成 N 份，不是器件插入损耗，也不是验收测量。本站为每个分光比另存一个规划插入损耗。本页的额外损耗等于规划插入损耗减去 10 log10(N)。批准设计前，用分光器规格书替换规划值。ITU-T G.671 把插入损耗定义为分支器件的规定参数，并没有给出这些规划数字。

  • 1:2：理想 3.010 dB，规划插入损耗 3.7 dB，额外损耗 0.690 dB。
  • 1:4：理想 6.021 dB，规划插入损耗 7.2 dB，额外损耗 1.179 dB。
  • 1:8：理想 9.031 dB，规划插入损耗 10.5 dB，额外损耗 1.469 dB。
  • 1:16：理想 12.041 dB，规划插入损耗 13.8 dB，额外损耗 1.759 dB。
  • 1:32：理想 15.051 dB，规划插入损耗 17.0 dB，额外损耗 1.949 dB。
  • 1:64：理想 18.062 dB，规划插入损耗 20.5 dB，额外损耗 2.438 dB。

单级 1:32 使用规划插入损耗 17.0 dB。10 km、0.25 dB/km 的光纤为 2.5 dB。4 对连接器按 0.3 dB 计为 1.2 dB，6 个熔接点按 0.1 dB 计为 0.6 dB。物理损耗为 17.0 + 2.5 + 1.2 + 0.6 = 21.3 dB。最小发送功率 +3 dBm 时，预计收光为 +3 - 21.3 = -18.3 dBm。0.25 dB/km、0.3 dB 和 0.1 dB 是计算器已采用的可编辑规划假设，不是 ITU-T G.652 限值，也不是现场测量。光模块等级和 ONU 门限仍以输入的发送端与 ONU 规格为准。

用同一组假设继续校核: PON分光损耗计算器 · 光功率预算计算器 · ONU收光检查 · PON与光纤计算器 · PON光网络专题.

可复算案例：10 km、1:8 × 1:8

总分光比 = 8 × 8 = 64（1:64），分光器损耗 = 10.5 + 10.5 = 21.0 dB。按0.30 dB/km计算，10 km光纤损耗为3.0 dB；6个熔接点为0.6 dB，4个连接器为1.2 dB，物理损耗合计25.8 dB；加入3 dB工程余量后，设计损耗 = 28.8 dB。1 dB光学代价从预算中扣除（GPON C+：33 dB − 1 dB = 32 dB），剩余3.2 dB。正式设计需替换为厂商规格和实测值。

校核步骤

  1. 用PON分光器损耗计算器确认级联比例和插入损耗。
  2. 用光纤链路损耗计算器拆分线路损耗。
  3. 用光功率预算计算器验证接收灵敏度和过载窗口。
  4. 现场使用光功率计与OTDR验收。

常见问题

多级级联能提高覆盖灵活性，但会增加连接点、插入损耗和维护复杂度；不能仅凭理论分光损耗批准设计。
