服务器机房增加3 kW显热后会发生什么？

这是工程示例。基础热量表的设计负荷是11.776 kW，约3.35冷吨。若房间内还有设备放出3 kW热，设计负荷升到15.226 kW，约4.33冷吨，两台8 kW机组的利用率从73.6%升到95.2%。

配套计算器

计算器没有可覆盖本例全部输入的网址预设。按下列数值手工输入后再对照结果。

打开制冷负荷计算器 →

热量表如果漏掉放在房间内的变压器、小型 UPS 或除湿机的显热部分，就会低估设计负荷。本例不改变 IT 千瓦数，只增加这一项。

示例假设

  • IT 8 kW，UPS 损耗 0.6 kW，PDU 损耗 0.3 kW，照明 0.4 kW，2 人按每人 120 W，围护 0.5 kW，其他 0.2 kW，余量 15%。
  • 已装两台，每台显冷量 8 kW。第一次额外显热为 0。第二次额外显热为 3 kW。

步骤

  1. 没有额外项时，基础负荷 = 10.24 kW，设计负荷 = 11.776 kW，约 3.35 冷吨。两台合计 16 kW，利用率 73.6%。停一台后剩 8 kW，低于 11.776 kW，N+1 不通过。
  2. 增加 3 kW 显热后，基础负荷 = 13.24 kW，设计负荷 = 15.226 kW，约 4.33 冷吨。同样两台的利用率为 95.2%，引擎会标成高利用率。N+1 仍然不通过，而且正常状态已经接近已装容量。

边界

这 3 kW 是释放在受控房间内的示例输入。排到室外的热不属于这一项。引擎不会把相对湿度换算成千瓦；湿度警告是另一项检查，不能代替这块显热。高利用率和 N+1 失败不是同一件事，增加 3 kW 之后两件都会出现。

来源：施耐德电气，计入房间内的每一项热源。
