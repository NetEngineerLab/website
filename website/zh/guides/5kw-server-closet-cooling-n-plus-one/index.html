5 kW服务器小间需要多少冷吨？

这是工程示例，不是调查过的机房。5 kW IT加上本表中的小房间得热后，设计显热为7.268 kW，约2.07冷吨。一台8 kW显冷量覆盖正常运行。N+1需要第二台也能单独承担7.268 kW。

5 kW IT2.07冷吨N+1示例
配套计算器

计算器没有可覆盖本例全部输入的网址预设。按下列数值手工输入后再对照结果。

打开制冷负荷计算器 →

制冷专题已经有 100 kW IT 机厅，热负荷指南有 120 kW 计算表。本例是单间小机房：看起来比 IT 铭牌更大的机组，仍可能配错 N+1。

示例假设

  • IT 5 kW，UPS 损耗 0.4 kW，PDU 损耗 0.2 kW，照明 0.2 kW，1 人按 120 W，围护 0.3 kW，其他显热 0.1 kW。
  • 余量 15%。单台显冷量 8 kW。送回风温差 10°C。没有额外潜热。

步骤

  1. 人员 = 0.12 kW。基础显热 = 6.32 kW。
  2. 设计负荷 = 6.32 × 1.15 = 7.268 kW。
  3. 冷吨 = 7.268 / 3.5168525 = 2.07 冷吨。这是显热冷吨，不是舒适性空调铭牌。
  4. 一台 8 kW：正常容量 8 kW，可以覆盖 7.268 kW。停机后剩余 0 kW，N+1 不通过。
  5. 两台 8 kW：正常容量 16 kW。一台停止后仍有 8 kW，可以覆盖 7.268 kW，这次 N+1 校核通过。引擎的运行台数是 1，建议台数是 2。

边界

不要把小间算成“5 kW 不到 2 冷吨，所以一台 2 冷吨舒适性空调就够”。舒适性总冷量不是服务器房间工况下的显冷量。计算器不模拟气流短路，也不模拟机组在房间温度下达不到 8 kW 显冷量。这不是 100 kW 机厅案例。
