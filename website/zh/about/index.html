关于 NetEngineerLab

NetEngineerLab 专注于通信与 IP 网络、光与 PON 工程、数据中心容量，以及通信 / 站点电源相关计算器，并提供把设计问题连到对应工具的短指南和专题。你填入的数值在浏览器里计算，不会上传。

发布者与内容复核

本站由 bin yaob（GitHub ddcodedog）运营与发布，同时维护 NetEngineerLab GitHub 组织与本网站。本页不宣称学历、职业认证、雇主隶属关系，也不宣称有多名编辑人员的团队编制。

职责
作为运营者、发布者与技术复核人，负责计算器页面、公式说明，以及页面上出现的标准引用。
如何复核
每个计算器写明方法、假设与限制；用到公式时写出公式和单位；只有页面明确引用的标准才会出现引用。若提供历史记录，保存在浏览器本地。上线前经过自动化引擎测试与站点发布检查。
联系
netengineerlab@outlook.com，见联系页。

站上有什么

工具目录目前列出 46 个计算器，按工作内容分组：光链路、PON 规划、维护与 OTDR、IP 与交换、通信和数据中心电源、无线链路、传输，以及运维。三组计算器入口把相关工具收在一起：PON 与光纤、交换与带宽、数据中心电源与制冷。

较长的说明在工程指南中心。专题把一个问题和对应的指南、计算器连起来，目前包括交换机超售、PON 光网络、数据中心容量、制冷容量、通信电源、摄像头带宽与 PoE，以及网络监控。

计算器怎么做出来

每个工具页说明这一页的算法、假设和限制。用到公式时，公式和单位写在该页上。某一页引用了标准时，引用就写在该页上，例如编址工具上的 RFC，或光链路工具上的 ITU-T 建议。页面没有引用标准，就不表示它遵循一份未写明的标准。

工具如果提供历史记录，记录保存在浏览器本地。

复核与更新

做过内容复核的页面会在正文里写明复核日期，常见形式是带有公式依据、适用边界和更新记录的「内容复核」区块。站点地图里的 lastmod 在可见标题、描述或正文发生变化时更新。只改页头页脚、脚本或版式，本身不会改这个日期。除了这些日期和各工具页上的说明，没有另外一份公开更新日志。
