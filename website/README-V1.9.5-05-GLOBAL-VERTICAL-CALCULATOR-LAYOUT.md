# NetEngineerLab V1.9.5-05

This release standardizes the main calculator workspace across all 14 tools.

## Layout change

- Input/parameter panel first.
- Result/analysis panel second.
- No desktop side-by-side height mismatch.
- No large blank area beneath the shorter column.
- The same logical order is preserved on tablet and mobile.

## Scope

The CSS layout and its cache keys were changed for all English and Chinese tool pages. Calculation formulas, JavaScript, datasets, SEO content, manifests, and icons were not changed.
