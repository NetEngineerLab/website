Methodology

How it’s calculated

class budget = Tx_min − Rx_sensitivity − path_penalty
physical loss = fiber + splices + connectors + splitters + other
design loss = physical loss + engineering margin
remaining = class budget − design loss
Rx = Tx_min − physical loss

Optical path penalty and engineering margin are budget terms, not present physical component losses, so receive power uses physical loss only.

Status rules

The verdict takes the tightest of three checks: remaining class budget, margin above receiver sensitivity, and margin below overload (using maximum transmit power).

PassAll three ≥ 3 dB
MarginalAny check between 0 and 3 dB
FailAny check below 0 dB
