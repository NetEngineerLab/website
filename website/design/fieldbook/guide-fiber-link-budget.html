Fiber link budget calculation: loss, margin and maximum distance

Plan a fiber link by adding connector, splice and fiber attenuation losses, then reserve engineering margin before comparing the result with transceiver power limits.

A fiber link works when the transmitter-to-receiver optical power window is wider than total path loss. A link budget makes every loss assumption visible.

Total loss = attenuation × distance + connector loss + splice loss + other passive loss
Margin = available budget − total loss

Worked example: 10 km single-mode link

Assume 0.35 dB/km attenuation, two connectors at 0.5 dB each, four splices at 0.1 dB each and 3 dB engineering margin.

Fiber 10 km3.5 dB
Connectors 2×1.0 dB
Splices 4×0.4 dB
Design loss (+3 dB)7.9 dB

Loss items to record

ItemExampleDesign note
Fiber attenuation0.35 dB/kmUse wavelength specification
Connector pair0.5 dB eachInclude patch panels
Fusion splice0.1 dB eachUse measured values when available
Engineering margin2–3 dBProtects aging and repairs

Approval workflow

  1. Record transceiver transmit and receive limits.
  2. Measure or estimate every passive loss.
  3. Add margin before comparing to the power budget.
  4. Check both directions for asymmetric optics.

Frequently asked questions

What does a negative margin mean?

The path loss exceeds the optical budget. Reduce loss or select optics with a larger budget.

Should connector loss be counted once or twice?

Count each mated connector pair in the optical path.
