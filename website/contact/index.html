Email

netengineerlab@outlook.com

This is the only public contact for the site. Use it for formula corrections, unclear page text and technical comments. A calculation still runs in your browser. Sending mail is not submitting a calculation.

What to write about

  • A formula, default, unit or limit on a page does not match the public reference it cites.
  • The same inputs disagree with your own arithmetic, and you can show the steps.
  • The English, Chinese or Spanish wording of the same tool disagrees.
  • A guide or topic page places a number in the wrong design step.
  • Cooperation or reuse of a page. Include the page address.

What to include

A note that only says the result is wrong is hard to check. Please include:

  • The tool name and the page address.
  • The values you entered, with units.
  • The result the page showed.
  • The result you expected, and the formula, standard clause or equipment note behind it.
  • The page language, if the problem appears in only one language.

What not to send

Do not email passwords, access tokens, customer configurations, live captures or tickets that still contain names and addresses. Calculation history stays in your browser. There is no need to export it and attach the whole record.

Whether a result can be used in a formal design is covered by the terms of use. A reply explains the page. It is not a site survey or a signed document.

Pages to check first

Many limits are already written on the page itself. Before writing, look at:

  • Tools: confirm which calculator you opened.
  • Guides: the formula, the example and the failure cases to check.
  • Privacy: calculation data stays local, and statistics are optional.
  • Terms: a result compares options and narrows a fault. It is not an acceptance by itself.
