How to Calculate Bandwidth and File Transfer Time

Estimate file transfer time from link speed, payload size and protocol overhead, with examples for WAN backups, cloud uploads and NOC planning.

Transfer-time estimates are useful for backup windows, migration plans and customer commitments. Start with file size in bits, divide by link rate, then apply a realistic efficiency factor.

Time = file size (bits) ÷ effective throughput (bits/s)
Effective throughput = link rate × efficiency

Worked example: 100 GB over a 1 Gbps link

100 GB is approximately 800 gigabits. At line rate, that is 800 seconds, or 13 minutes 20 seconds. With 85% effective throughput, the estimate becomes about 15 minutes 41 seconds.

Choose a realistic efficiency

ConnectionPlanning efficiencyWhy
LAN bulk flow90–95%Low latency and few queues
Internet or VPN70–90%Encryption, RTT and congestion
Shared Wi-Fi40–70%Contention and retransmits

Transfer planning checklist

  1. Convert decimal or binary file units consistently.
  2. Use actual negotiated link speed.
  3. Apply efficiency and utilization.
  4. Add a schedule buffer for production work.

Frequently asked questions

Why is a 1 Gbps transfer not exactly 125 MB/s?

Headers, storage limits, encryption and congestion reduce payload throughput.

Should I use Mbps or MB/s?

Network links use bits per second; file systems report bytes per second. Multiply bytes by eight before dividing.
