A 370 W PoE Budget Feeds 16 Cameras. Does It Feed 24?

Example only, not a switch datasheet. Sixteen cameras at 12 W each need 271.06 W after cable loss and headroom, 73.26% of a 370 W budget. Twenty-four cameras need 406.59 W and fail. The same inputs allow 21 cameras.

The camera topic already plans bitrate and uplinks. This example is only the PoE watt budget. Far-end voltage is a different check in the PoE voltage drop calculator; the 90 m, 26 AWG case can fail while this watt check still passes.

Example assumptions

  • Switch budget 370 W. 24 PoE ports. Each camera draws 12 W. Cable-loss allowance 15%. Planning headroom 20%. Class check: IEEE 802.3at, whose PD limit in this calculator is 25.5 W.
  • The 12 W draw and the 15% and 20% allowances are example inputs. They are not class maximums and not an IEEE requirement.

Steps

  1. Source power per camera = 12 / 0.85 = 14.12 W.
  2. Sixteen cameras need 14.12 × 16 × 1.20 = 271.06 W. Remaining budget 98.94 W. Utilization 73.26%. Ports, budget and the 25.5 W class check all pass.
  3. Twenty-four cameras need 406.59 W, 109.89% of 370 W. The budget check fails. The largest count that still fits the budget and the port count is 21.

Boundary

This does not check voltage at the camera, startup surge or a port that is limited below the class. IEEE 802.3 is the public standards home for the class names used here. Read the switch budget and the camera draw from the equipment, then type them in. There is no URL preset for this sheet.

Public source: https://www.ieee802.org/3/.
