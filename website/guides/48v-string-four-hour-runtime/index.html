Will One 100 Ah String Cover Four Hours at 600 W?

Example only, not a site discharge test. One 24-cell 100 Ah string feeding 600 W lasts 5.584 hours in this calculator's Peukert model. The 4 hour target still passes. The nameplate 100 Ah does not mean 100 divided by the load current.

The rectifier guide sizes modules. The generator guide sizes fuel. This example answers a different question: how long the battery string itself can carry a stated DC load.

Example assumptions

  • 24 lead-acid cells. Nominal 2.0 V, start 2.1 V, cutoff 1.75 V. One string, 100 Ah rated at 10 hours. Peukert exponent 1.15.
  • Path efficiency 95%. Depth of discharge 80%. Age, temperature and curve factors 100%. Load 600 W with no extra margin. Target 4 hours. Model: Peukert.

Steps

  1. Nominal bus = 48 V. Start = 50.4 V. Cutoff = 42 V. Average voltage = 46.2 V.
  2. Battery power = 600 / 0.95 = 631.58 W. Average current = 631.58 / 46.2 = 13.67 A.
  3. Usable capacity = 100 Ah × 0.80 = 80 Ah. The simple estimate is 80 / 13.67 = 5.852 hours.
  4. Peukert runtime = 5.584 hours. The gap above 4 hours is 1.584 hours. The same target needs 74.82 Ah in this string, so one 100 Ah string still covers it.

Boundary

This is the calculator's Peukert estimate, not a manufacturer discharge curve. The sheet warns that the rate is in the medium band and that current rises as voltage falls. Age, cold temperature or a deeper cutoff can miss the 4 hours even when this sheet passes. Do not treat the result as measured autonomy.
