The Battery Lasts 21.25 Minutes. Do Two UPS Modules Survive One Failure?

Example only, not a site acceptance test. A 30 kW load at power factor 0.9 needs 33.33 kVA. Two 20 kVA modules fail the one-module-out check. The same battery still runs 21.25 minutes, above a 15 minute target.

The capacity topic already has a 160 kW path example. This page separates UPS module redundancy from battery minutes.

Example assumptions

  • Load 30 kW. Load power factor 0.9. No extra headroom. UPS efficiency 94%. Output power factor 0.9. Module size 20 kVA. Redundancy modules: 1.
  • Battery bus 384 V. One 40 Ah string. Depth of discharge 80%. Battery efficiency 92%. Aging and temperature factors 100%. Target 15 minutes.

Steps

  1. Load is 30 / 0.9 = 33.33 kVA. Two 20 kVA modules provide 40 kVA, so the normal state fits, but one module left is 20 kVA. 20 × 0.9 = 18 kW, which is below 30 kW. N+1 fails. The recommended count is 3.
  2. Nominal battery energy = 384 × 40 / 1000 = 15.36 kWh. Usable energy = 11.30 kWh. Runtime = 21.25 minutes, so the 15 minute target passes. The 15 minute target needs 28.23 Ah in this string.
  3. Install the third 20 kVA module and the one-module-out check passes. Runtime stays 21.25 minutes. Another module does not add battery minutes.

Boundary

The calculator does not use a manufacturer battery curve, recharge current limits or a measured transfer time. A passing runtime does not mean the remaining module can carry the load.
