How to Calculate an IPv4 Subnet: CIDR, Hosts and Usable Ranges

Calculate IPv4 subnets from CIDR notation, find network and broadcast addresses, and verify usable host capacity with a repeatable engineering method.

Subnetting turns one IPv4 block into smaller broadcast domains. The reliable workflow is to read the prefix length, calculate the address count, then reserve network and broadcast addresses before assigning hosts.

Total addresses = 2^(32 − prefix length)
Usable hosts = total addresses − 2

Worked example: 192.168.10.0/24

A /24 leaves 8 host bits. That gives 256 total addresses, from 192.168.10.0 through 192.168.10.255. The network address is .0, the broadcast address is .255, and the usable range is 192.168.10.1–192.168.10.254.

A practical subnetting workflow

  1. Calculate host bits as 32 minus the prefix.
  2. Confirm the network boundary and broadcast address.
  3. Reserve infrastructure addresses before counting client capacity.
  4. Check overlap with existing routes.

Frequently asked questions

How many usable hosts are in a /27?

A /27 has 32 total addresses and 30 usable host addresses.
