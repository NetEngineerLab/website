What Happens If a Server Room Gains 3 kW of Extra Sensible Heat?

Example only. The base sheet designs to 11.776 kW, about 3.35 tons. Adding 3 kW for equipment that also releases heat in the room raises the design load to 15.226 kW, about 4.33 tons, and two 8 kW units move from 73.6% to 95.2% of capacity.

A heat sheet that forgets a transformer, a small UPS sitting inside the room, or a dehumidifier’s sensible component understates the design load. This example adds that term without changing the IT kilowatts.

Example assumptions

  • IT 8 kW, UPS loss 0.6 kW, PDU loss 0.3 kW, lighting 0.4 kW, two people at 120 W, envelope 0.5 kW, other 0.2 kW, headroom 15%.
  • Two installed units, 8 kW sensible each. First run extra sensible = 0. Second run extra sensible = 3 kW.

Steps

  1. Without the extra term, base load = 10.24 kW and design load = 11.776 kW, about 3.35 tons. Two units provide 16 kW, utilization 73.6%. After one stop, 8 kW is below 11.776 kW, so N+1 fails.
  2. With 3 kW extra sensible heat, base load = 13.24 kW and design load = 15.226 kW, about 4.33 tons. Utilization on the same two units is 95.2%, which the engine flags as high. N+1 still fails, and the normal state is now close to the installed capacity.

Boundary

The 3 kW term is an example input for heat released inside the conditioned room. Heat rejected outdoors does not belong in it. The engine does not convert relative humidity into kilowatts; a humidity warning is a separate check and is not a substitute for this sensible term. High utilization is not the same failure as N+1, and both are present after the extra 3 kW.

Source: Schneider Electric, include every heat source inside the room.
