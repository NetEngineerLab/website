EVPN Control Plane Up, Data Plane Down Lab

Diagnosa size- tergantung EVPN / VXLAN kehilangan melalui delapan tahap interaktif dan sepuluh bukti pos pemeriksaan.

Skenario pendidikan sintetis. Tidak ada akses perangkat hidup, menangkap pelanggan atau reproduksi insiden nyata. Hanya memori peramban; reset membersihkan kemajuan pembelajaran.

Diulang: 2026-10-16

Satu.

Presiden A198.51.100.10 / 24 dan CE-B198.51,100.20 / 24 berbagi VLAN100 / VNI10100 / BD100 di dua Hujan. 1472-byte muatan ICMPv4 dengan DF gagal di kedua arah; 32-byte probe lulus. Hal ini size- tergantung kerugian, tidak setiap ping gagal.

Cea LeafA / VTEP192.11 Underlay LeafB / VTEP192.12

2, bukti yang bagus.

BGP EVPN didirikan; diperkirakan rute MAC diimpor dan dipasang; VNI10100 naik. Fakta-fakta ini menunjukkan konteks sinyal. Mereka tidak menguji amplop paket yang dirangkum secara lengkap.

3, cek berikutnya?

Pilih sebuah keimanan. mengungkapkan pengamatannya dan menjelaskan apa yang dapat dan tidak dapat membangun. Periksa semua keimananmu sebelum mempersempit domain kesalahan.

4.

Domain kesalahan narrow

Gunakan set bukti lengkap untuk memilih domain kesalahan. Paket kecil dan layanan pemetaan harus didamaikan dengan tetes size- korelasi.

Diagnosa akhir

Pilih penyebab bahwa akun untuk 1422 / 1423- byte perilaku batas dan keluar diamati MTU tetes.

Verifikasi

Simulasi pendidikan saja. Pertama validasi setiap link / path yang relevan dan kedua arah ditambah platform IP-MTU konvensi. Profil post- fix1600 adalah ditiupkan, bukan rekomendasi universal. Mengurangi layanan MTU adalah alternatif dengan pertukaran titik akhir / aplikasi.

Pelajaran belajar

Penyelesaian memerlukan diagnosis yang didukung dan menjalankan verifikasi simulasi. Kondisi kontrol pesawat secara sehat tidak membuktikan pengiriman; bukti harus menghubungkan resolusi titik akhir, pemetaan layanan, encapsulasi aktual, batas-batas ukuran dan hubungan tetes.

  1. Pertahankan konteks packet- ukuran / DF / arah dengan setiap probe.
  2. Perlakukan IPv6 ND dan anycast sebagai pemeriksaan kondisional, bukan tersangka universal.
  3. Mengembalikan jalan penuh dan pemulihan setelah perubahan terkendali.
