About NetEngineerLab

NetEngineerLab builds calculators, knowledge resources, MIB/OID references, fault cases and troubleshooting tools for telecom and network engineers. The first release focuses on optical and PON engineering.

Current service

NetEngineerLab currently provides 20 bilingual online tools covering optical networks, IP planning, power, wireless links and infrastructure capacity. The tools run in the browser and are maintained as a production service.
