# Topic Hub Rule Update Report

Updated the NetEngineerLab Topic Growth & GitHub Sync Development Standard to V1.1.

Added:

- Mandatory Topic Hub for each core topic.
- Topic Hub must aggregate all active website content for that topic.
- Topic Hub must link published GitHub engineering resources.
- Topic Hub must be updated whenever an article, guide, tool, example, or GitHub document changes.
- Topic Hub requirements added to the release gate.
- `/topics/<topic-slug>/` and `/zh/topics/<topic-slug>/` added to the directory standard.
- Local `docs/...md` paths must not be exposed as website links; published GitHub URLs should be used.
