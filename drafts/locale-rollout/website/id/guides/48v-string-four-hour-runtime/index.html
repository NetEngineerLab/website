Akankah 100 Ah String Tutup Empat Jam di 600 W?

Contoh saja, bukan sebuah situs tes debit. Satu 24- sel 100 Ah string makan 600 W berlangsung Tendang 5.584 jam dalam model Peukert kalkulator ini. Target 4 jam masih lewat. Plat nama 100 Ah tidak berarti 100 dibagi dengan load saat ini.

Buka kalkulatornya.

Pemandu refiser modul ukuran. Pemandu generator bahan bakar ukuran. Contoh ini menjawab pertanyaan yang berbeda: berapa lama string baterai itu sendiri dapat membawa beban DC yang dinyatakan.

Contoh asumsi

  • 24 sel asam. Nominal 2.0 V, mulai 2,1 V, cutoff 1,75 V. Satu string, 100 Ah dinilai pada 10 jam. Peukert eksponen 1.15.
  • Efisiensi tapak 95%. Kedalaman debit 80%. Umur, suhu dan faktor kurva 100%. Isi 600 W tanpa margin tambahan. Target 4 jam. Peukert.

Langkah

  1. Bus Nominal = 48 V. Mulai = 50.4 V Pemotongan = 42 V. Tingkat Rata-rata tegangan = 46.2 V.
  2. Daya baterai = 600 / 0.95 = 631.58 W. Rata-rata saat ini = 631.58 / 46.2 = 13.67 A
  3. Kapasitas dapat digunakan = 100 Ah × 0.80 = 80 Ah. Perkiraan sederhana adalah 80 / 13.67 = 5.852 jam.
  4. Peukert runtime = 5.584 jam. Jarak di atas 4 jam adalah 1.584 jam. Target yang sama membutuhkan 74.82 Ah dalam string ini, sehingga satu 100 string Ah masih menutupinya.

Batas

Ini adalah perkiraan kalkulator Peukert, bukan kurva debit produsen. Lembar ini memperingatkan bahwa rate berada di band menengah dan bahwa saat ini naik sebagai tegangan jatuh. Umur, suhu dingin atau cutoff lebih dalam dapat melewatkan 4 jam bahkan ketika lembar ini berlalu. Jangan perlakukan hasilnya seperti otonomi terukur.
