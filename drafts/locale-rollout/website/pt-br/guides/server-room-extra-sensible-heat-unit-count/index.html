O que acontece se uma sala de servidor ganha Jornal 3 kW de calor extra sensível?

Apenas exemplo. A folha de base projeta para 11,776 kW, cerca de 3,35 toneladas. Adicionar 3 kW para equipamentos que também liberam calor na sala eleva a carga de projeto para 15,226 kW, cerca de 4,33 toneladas, e duas 8 unidades kW mover de 73,6% para 95,2% de capacidade.

Uma chapa de calor que esquece um transformador, um pequeno UPS sentado dentro da sala, ou o componente sensível de um desumidificador subestima a carga de projeto. Este exemplo acrescenta esse termo sem alterar os kilowatts de TI.

Suposições de exemplo

  • IT 8 kW, UPS perda 0,6 kW, PDU perda 0,3 kW, iluminação 0,4 kW, duas pessoas a 120 W, envelope 0,5 kW, outros 0,2 kW, headroom 15%.
  • Duas unidades instaladas, 8 kW sensíveis cada. Primeira execução extra sensível = 0. Segunda corrida extra sensível = 3 kW.

Passos

  1. Sem o termo extra, carga de base = 10,24 kW e carga de projeto = 11,776 kW, cerca de 3,35 toneladas. Duas unidades fornecem 16 kW, utilizando 73,6%. Após uma parada, 8 kW está abaixo de 11,776 kW, então N+1 falha.
  2. Com 3 kW calor extra sensível, carga de base = 13,24 kW e carga de projeto = 15,226 kW, cerca de 4,33 toneladas. A utilização nas mesmas duas unidades é 95,2%, que o motor sinaliza como alta. N+1 ainda falha, e o estado normal está agora perto da capacidade instalada.

Limite

O termo 3 kW é uma entrada de exemplo para o calor liberado dentro da sala condicionada. O calor rejeitado ao ar livre não pertence a ele. O motor não converte umidade relativa em kilowatts; um aviso de umidade é uma verificação separada e não é um substituto para este termo sensível. Alta utilização não é a mesma falha que N+1, e ambos estão presentes após o extra 3 kW.

Fonte: Schneider Electric, inclui todas as fontes de calor dentro da sala.
