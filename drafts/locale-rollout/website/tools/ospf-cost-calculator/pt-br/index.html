Calculadora de custo OSPF

Calcule Automóveis métricas de interface a partir de largura de banda de referência, compare custos de caminho e identifique candidatos multicaminho de igual custo. Todos os cálculos são executados localmente.

IN

Entradas

Digite uma interface por linha: nome, largura de banda Mbps, sobreposição métrica opcional, opcional desactivada.

Digite uma interface por linha: name, bandwidth Mbps, optional metric override, optional disabled.

Cálculo do núcleo

Interface cost = clamp(round(ReferenceBw ÷ InterfaceBw), 1, 65535). Path cost = Σ active interface costs. ECMP = paths sharing the lowest path cost.

Largura de banda de referência. Os padrões do fornecedor costumam usar 100 Gbps ou 40 Gbps como numerador.

Arredondamento. O teto corresponde ao comportamento comum da Cisco/FRR; piso e mais próximo estão disponíveis para verificações de políticas.

Substitui. As métricas manuais são preservadas e sinalizadas para que o custo automatizado nunca ganhe silenciosamente.

ECMP. Custos de rota iguais mais baixos são candidatos multicaminho após verificação da adjacência e da política de área.

SO

Resultado da engenharia

Custo ativo, melhor caminho e candidatos ECMP do modelo de largura de banda de referência.

    Metodologia
    O custo do OSPF é a largura de banda de referência dividida pela largura de banda da interface, arredondada ao modo inteiro selecionado e delimitada a 1–65535. Uma sobreposição manual métrica é preservada e marcada para revisão. O custo do caminho é a soma dos custos da interface ativa; os caminhos com o mesmo custo mais baixo são candidatos ao ECMP.
    Validar largura de banda de referência, predefinições do fornecedor, política de área, velocidade de interface e estado de adjacência antes das mudanças de produção.
    Perguntas mais frequentes
    Como é calculado o custo OSPF?
    O custo OSPF é a largura de banda de referência dividida pela largura de banda da interface, arredondada para um-13 inteiro e limitada a 1 até 65535.
