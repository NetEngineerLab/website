Bagaimana jika kedatangan sama dengan layanan?

Model tidak stabil. Halaman menolaknya.

Apakah hasil 5 meter pengukuran?

Apakah tingkat per- menit mengubah formula?

Hanya unit konversi. Formula antrian menggunakan rate per-second.

Tidak. Ini adalah salah satu server.
