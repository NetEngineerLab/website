Sobre e aplicabilidade

Use isso para um único servidor com chegadas Poisson e serviço exponencial. Não é um modelo de bu de buffer e não inclui serialização de um frame em particular.

Esta é uma aproximação de engenharia para o planeamento. Não é uma medição laboratorial e não garante o desempenho do equipamento.

Revisão de conteúdo: 2026-11-19

Como é calculado

ρ = λ / μ; E[ T] = 1 / (μ − λ); E[ W] = ρ / (μ (1 − ρ)).

Para uma fila M/M/1 o uso é ρ = λ/μ e a fila é estável apenas quando μ > λ. O tempo médio de permanência é 1/(μ−λ). O tempo médio de espera na fila é ρ/(μ(1−ρ)). A contagem média do sistema é ρ/(1−ρ) e a contagem média da fila é ρ2/(1−ρ). Um caso trabalhado é λ = 800 por segundo e μ = 1000 por segundo: ρ = 0,8, permanência = 5 ms, espera = 4 ms. As entradas por minuto são divididas por 60 antes dessas fórmulas.

FAQ

E se a chegada for igual a serviço?

O modelo é instável. A página rejeita-a.

O resultado de 5 ms é uma medição?

Não. É 1/200 segundo para as taxas trabalhadas.

As taxas por minuto alteram a fórmula?

Apenas a conversão da unidade. As fórmulas de fila usam taxas por segundo.

Posso modelar muitos servidores?

Não. Este é um servidor.
