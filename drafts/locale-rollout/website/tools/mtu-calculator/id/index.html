    Metode

    METHODOLOGY

    TCP MSS

    RFC 6691 merekomendasikan pengurangan hanya IP tetap dan header TCP ketika mengiklankan MSS. Alat secara terpisah menghitung data yang sebenarnya setelah opsi yang dikonfigurasi.

    PPPoE

    RFC 2516 menggunakan 6 bytes untuk header PPPoE dan 2 bytes untuk field protokol PPP, menghasilkan akrab 1492-byte MTU pada sebuah muatan EtherNaikkan 1500- byte.

    VLAN dan MPLS

    A VLAN tag adalah 4 bytes pada kawat. Setiap entri label MPLS adalah 4 bytes. VLAN biasanya tidak mengurangi IP MTU terkonfigurasi ketika ekspansi frame tag-frame didukung.

    Terowongan dan keamanan

    GRE, VXLAN, IPsec dan WireGuard overhead tergantung pada versi IP luar dan bidang opsional. IPsec padding adalah variabel, sehingga preset adalah perkiraan editable.

    Referensi primer: RFC 2516 · RFC 6691 · RFC 2784 · RFC 2890 · RFC 7348 · RFC 3032 · RFC 4303 · RFC 8200 · RFC 8201 · Wire Guard Protocol

    FAQ

    Mengapa PPPoE MTU biasanya 1492?

    Sebuah 1500- byte muatan Ethernet dikurangi 8 byte dari PPPoE dan protokol PPP overhead daun 1492 bytes.

    Haruskah VLAN selalu mengurangi IP MTU dengan 4 bytes?

    Tidak. Paling mampu perangkat Ethernet mendukung frame tag sedikit lebih besar sambil menjaga IP MTU di 1500. infect Gunakan mode ketat hanya ketika batas fisik frame tidak memperluas.

    Mengapa nilai IPSEC diperkirakan?

    overhead ESP tergantung pada luar IP, NAT- T, IV, tag integritas dan padding variabel. Verifikasi isi cipher sebenarnya dan implementasi vendor.

    Apa TCP MSS yang benar untuk IPv6 MTU 1500?

    Dengan header tetap saja, 1500 - 40- byte IPv6 header - 20- byte TCP header = 1440 bytes.

    Bisakah ping membuktikan jalur lengkap MTU?

    Ini berguna tapi tidak meyakinkan. Kelembaban ICMP, ECMP, terowongan dan routing asimetris dapat mempengaruhi hasilnya. Gabungkan dengan PMTUD, menangkap dan penghitung perangkat.

    Apa IPv6 MTU di bawah 1280 berarti?

    IPv6 mendefinisikan 1280 bytes sebagai link minimum MTU. Desain di bawah ini yang memerlukan pecahan lapisan-rendah / menyesuaikan kembali atau adaptasi dan harus ditinjau.
