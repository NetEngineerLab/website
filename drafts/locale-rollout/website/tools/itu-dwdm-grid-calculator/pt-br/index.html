Sobre e aplicabilidade

Use isto quando um plano DWDM nomear canais como um deslocamento inteiro de 193.1 THz. O comprimento de onda é o comprimento de onda de vácuo dessa frequência. Não inclui o índice de grupo eficaz de fibra, a tolerância de comprimento de onda de um transceptor, ou um mapa de canal fornecedor.

Esta é uma aproximação de engenharia para o planeamento. Não é uma medição laboratorial e não garante o desempenho do equipamento.

Revisão de conteúdo: 2026-11-19

Como é calculado

f = f anchor + n × espaçamento; λ = c / f, com c = 299792458 m/s.

ITU-T G.694.11 ancora a grade de frequência DWDM em 193,1 THz. Um índice de canal n e um espaçamento em hertz dão f = 193,1 THz + n × espaçamento. O comprimento de onda de vácuo segue λ = c / f. A velocidade da luz usada aqui é o valor exato SI 299792458 m/s, entãoÍN em nanometros é 299792.458 / f em terahertz. As linhas vizinhas usam o mesmo espaçamento. A mudança da âncora é permitida para um estudo de o quê-se; a âncora da grade publicada permanece 193,1 THz.

FAQ

1550 nm é exatamente o canal 0?

Não. Canal 0 a 193.1 THz tem um comprimento de onda de vácuo de 299792.458 / 193.1 nanometros, cerca de 732.52 nm.

Será que um índice negativo vai para um comprimento de onda mais longo?

Sim. Uma frequência mais baixa é um comprimento de onda de vácuo mais longo.

Isto pode substituir uma folha de dados do transceptor?

Não. Ele só converte a definição de grade que você digita.

Por que o espaçamento não é fixado em 100 GHz?

G.694.1 também define outros espaçamentos. O espaçamento é uma entrada.
