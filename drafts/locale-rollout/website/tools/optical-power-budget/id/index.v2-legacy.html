METHODOLOGY

Metode dan catatan rekayasa

Anggaran ODN standar

Minimum mengirimkan daya minus penerimaan sensitivitas minus penalti jalur optik. GPON B + memungkinkan hingga 28 dB ODN kerugian, sementara C + memungkinkan hingga 32 dB.

Kehilangan ODN Fisik

Kehilangan fiber + splice kehilangan + konektor kehilangan + multi- stage kehilangan + pasif lainnya kehilangan.

Total desain kerugian ODN

Kehilangan ODN Fisik + margin rekayasa. Margin meliputi penuaan, suhu, pemeliharaan koneksi dan variasi pengukuran.

Perkiraan menerima kekuatan

Minimum mengirimkan daya minus fisik ODN kerugian. Penalti jalur optik dan margin rekayasa adalah istilah anggaran, bukan kerugian komponen fisik.

Contoh standar baku

GPON Referensi C + downstream: + 3 dBm minimum mengirimkan daya, sampai 30 dBm ONU sensitivitas, Kore8 dBm overload dan 1 dB Penalti jalur optik; 10 km di 1490 nm, primer 1: 8 ditambah sekunder 1: 8, 6 splitces, 4 konektor dan 3 dB margin rekayasa.

ITU-T mendefinisikan kelas optik sistem dan ODN kehilangan berkisar. Untuk XGS-PON (ITU-T G.9807.1), masukkan daya, sensitivitas penerima, ambang batas beban dan batas optik dari peralatan yang dikerahkan; alat ini tidak memiliki XGS preset dan tidak boleh menyimpulkan nilai XGS dari GPON B + / C +. Splice, connector dan fiber adtenuation asumsi harus tetap disesuaikan dengan aturan perusahaan, komponen spesifikasi dan data lapangan.

Komponen pemeriksaan komponen

Fisik ODN loss = fiber attenuation length + splitter loss + connector loss + splice loss + other pasif loss. Untuk kasus bawaan: 3.0 dB serat + 21.0 dB splitters + 1.2 dB konektor + 0.6 dB splits = 25.8 dB fisik ODN kehilangan, dan 3 dB margin rekayasa menyebabkan kerugian desain 28.8 dB. 1 dB Penalti jalur optik tidak ditambahkan ke kerugian; ini dipotong dari anggaran: + 3 dBm − (−30 dBm) − 1 dB = 32 dB standar ODN anggaran, meninggalkan 3.2 dB sisa (90% dari anggaran yang digunakan). + 3 dBm minimum mengirimkan daya oleh karena itu memprediksi Kore22.8 dBm menerima kekuatan, 7.2 dB di atas sensitivitas; di + 7 dBm maksimum mengirimkan daya penerima tetap 10,8 dB di bawah Kore8 dBm batas beban. The margin rekayasa tidak dihentikan dari menerima kekuasaan.

GPON B + (28 dB) dan C + (32 dB) label adalah kelas referensi dari profil standar yang dipilih, bukan jaminan untuk setiap OLT/ONU sepasang. Konfirmasi pemancar aktual, sensitivitas penerima, kelebihan beban, panjang gelombang dan ODN kelas di database peralatan. Lanjutkan rugi serat untuk akuntansi rute atau Pusat topik PON & Optik untuk alur kerja desain.

FAQ

Pertanyaan yang sering ditanyakan

Mengapa perubahan baku ke GPON C + ketika 1: 8 × 1: 8 ditahan?

A: 8 x 1: 8 cascade berkontribusi sekitar 21 dB kehilangan splitter. Dengan serat 10 km, konektor dan splitces, fisik ODN kerugian adalah 25.8 dB; menambahkan 3 dB margin rekayasa memberikan desain ODN kehilangan 28.8 dBItu di atas 28 dB Batas B + tetapi dalam 32 dB C + budget (33 dB transmit--to -sensitivitas jendela minus 1 dB Penalti jalur optik), meninggalkan 3.2 dB.

Bagaimana anggaran listrik berbeda dari rugi serat?

Kehilangan serat langkah-langkah rute dan kerugian komponen. Anggaran daya juga menggabungkan daya, sensitivitas penerima dan batas beban untuk menentukan apakah peralatan dapat beroperasi dengan baik.

Mengapa menggunakan daya transmisi minimum?

Desain diperiksa dengan kondisi terburuk untuk menghindari hasil yang optimis disebabkan oleh peralatan variasi, penuaan dan suhu.

Apakah lebih tinggi menerima kekuasaan selalu lebih baik?

Tidak. Kekuatan rendah bisa jatuh di bawah sensitivitas, sementara daya yang berlebihan bisa melampaui batas overload. Menerima kekuatan harus tetap di dalam jendela yang diizinkan.

Mengapa margin rekayasa tidak dipotong dari menerima kekuatan?

Marjin teknik adalah cadangan desain, bukan kerugian fisik saat ini. Hal ini digunakan untuk verifikasi anggaran sementara menerima kekuasaan menggunakan kerugian fisik.

Mengapa jarak maksimum hanya perkiraan?

Jarak aktual juga tergantung pada tipe kabel, suhu, kualitas splice, rute dan parameter peralatan.

Bisakah hasil ini digunakan untuk penerimaan akhir?

Alat ini mendukung perencanaan dan penyerapan. Penerimaan akhir harus menggunakan daya meter dan OTDR pengukuran, spesifikasi dan standar perusahaan.

Koreksi jendela dan referensi resmi

Daya pengiriman minimum digunakan untuk pemeriksaan sensitivitas dan kehilangan anggaran. Daya pengiriman maksimum dicentang secara terpisah terhadap overload penerima; menggunakan hanya nilai minimum dapat menyembunyikan risiko pendek-link overload. Preset adalah referensi perencanaan, bukan substitusi untuk OLT / ONU atau transceiver datesheet. Batas dB Healthy / Caution adalah ambang batas perencanaan alat ini, bukan mandat standar universal.

Dasar Formula
