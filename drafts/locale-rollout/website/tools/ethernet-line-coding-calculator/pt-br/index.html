Sobre e aplicabilidade

Use isso para transformar uma taxa de carga útil MAC na taxa de linha mais alta implícita por um código de linha Ethernet publicado. Não escolhe um PMD, uma contagem de faixas ou um alcance.

Como é calculado

Taxa de linha = carga × (bits de código / bits de carga). RS-FEC multiplica uma relação de palavras de código extra.

8b/10b expande 8 bits de carga útil em 10 bits de linha, então a proporção é 10/8. 64b/66b usa 66/64. RS(528.514) adiciona 528/514 em cima de 64b/66b. RS(544,514) adiciona 544/514 em cima de 64b/66b. Uma carga útil 10 Gbps com 64b/66b é exatamente 10.3125 Gbps. A calculadora aplica apenas essa proporção. Auto-negociação, marcadores de alinhamento e um mapeamento de pista de uma determinada cláusula estão fora do resultado.

FAQ

10.3125 Gbps é uma taxa medida?

É a expansão exata 66/64 de 10 Gbps.

O RS-FEC substitui o 64b/66b?

Não. As predefinições multiplicam ambas as proporções.

TV.

Não. É a aritmética linear do código selecionado.

De onde vêm as proporções?

São os tamanhos 8b/10b, 64b/66b, RS(528.514) e RS(544.514) utilizados pela IEEE 802.3.
