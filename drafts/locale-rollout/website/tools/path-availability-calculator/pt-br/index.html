Sobre e aplicabilidade

Use isto para blocos independentes. Ele não modela o poder compartilhado, software comum ou um calendário de manutenção. O tempo de inatividade anual usa um ano de 365 dias.

Esta é uma aproximação de engenharia para o planeamento. Não é uma medição laboratorial e não garante o desempenho do equipamento.

Revisão de conteúdo: 2026-11-19

Como é calculado

Série A = A i. Paralelo A = 1 − □(1 − A i). A = MTBF / (MTBF + MTTR).

Se cada bloco falhar de forma independente, a disponibilidade de séries é o produto das disponibilidades. Disponibilidade paralela é um menos o produto das indisponibilidades. Dois caminhos Receita de 0,999 em paralelo dar 1 - 0,001×0,001 = 0,999999. MTBF e MTTR na mesma unidade de tempo dar A = MTBF / (MTBF + MTTR). Os minutos esperados em 365 dias são (1−A)×525600. Introduza disponibilidades como fracções construtores de pouco mais de 0 a 1, um bloco por vírgula.

FAQ

O paralelo vence sempre as séries?

Para os mesmos blocos independentes, a combinação paralela é maior.

A disponibilidade pode ser exatamente 1?

Sim. O tempo de parada é então zero neste modelo.

Porquê rejeitar zero?

Um bloco zeroformou um modelo de falha diferente de uma disponibilidade positiva.

0,999999 é um SLA medido?

Não. É a aritmética de dois 0,999 blocos.
