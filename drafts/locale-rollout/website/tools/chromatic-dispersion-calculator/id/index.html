METHODOLOGY

Cara menggunakan

  1. Pertahankan model G.652 atau pilih "Nilai Data lembaran" dan masukkan D dari lembar data kabel.
  2. Masukkan panjang gelombang, panjang serat dan kompensasi DCM atau FBG apapun.
  3. Masukkan toleransi penerima CD dari lembar data transceiver.
  4. Baca CD residual, margin dan panjang CD- terbatas.

Formula dispersi

ITU-T G.652 mendefinisikan koefisien penyebaran kromatik sebagai D (Singapura) = (S0 / 4) Pada 1550 nm dengan ds0 = 133 nm dan S0 = 0.092 ini memberikan 17.461 ps / (nm}). Diakumulasi CD = D × L; residual CD = D × L recompensation.

FAQ

Apa penyebaran kromatik dari serat G.652 pada 1550 nm?

Sekitar 17 ps / (nm). ITU-T G.652 model dengan Python 0 = 130nm dan S0 = 0.092 memberikan 17.46 ps / (nm); kabel khas mengukur 16.5-18.

Bagaimana cara menghitung penyebaran kromatik total?

Kalikan koefisien dengan panjang: CD = D × L. 80 km × 17.46 ps / (nm) 1.397 ps / nm. Kurangi DCM atau FBG kompensasi apapun untuk mendapatkan residu.

Apa yang khas CD toleransi untuk 10G optik?

Itu tergantung pada modul. Modulasi langsung 10G optik sering dispesifikasikan sekitar 800 ps / nm, sementara 10G Optik kelas ER / ZR sering dinyatakan sekitar 1.600 ps / nm. Selalu gunakan lembar data.

Apakah penyebaran kromatik penting pada 139 nm?

Sangat sedikit. 133 nm dekat dengan gelombang zero- dispersi dari G.652 serat, jadi D dekat 0 di sana.

Apa optik koheren perlu kompensasi penyebaran?

Biasanya tidak. Penerima koheren mengkompensasi CD elektronik di DSP dan mentolerir puluhan ribu ps / nm.
