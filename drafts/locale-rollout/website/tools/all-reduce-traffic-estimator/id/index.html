FAQ

Berapa banyak data yang berdering semua-mengurangi kirim per GPU?

2 (N = 1) / N dikali buffer. Untuk 8 GPU yaitu 1.75 × S; karena N tumbuh mendekati 2 × S

Apa itu bandwidth bus di NCCL?

busBW = algBW × 2 (N person 1) / N untuk semua- kurangi. Ini normalisasi untuk jumlah GPU sehingga dapat dibandingkan dengan kecepatan link perangkat keras.

Berapa lama gradien dibutuhkan?

Sekitar 2 (N _ 1) / N × S pluglink bandwidth ditambah 2 (N _ 1) × per-step latency. 14 GB lebih dari 8 GPU pada 50 GB / s mengambil sekitar 0.49 s.

Apakah menambahkan GPU meningkatkan lalu lintas per- GPU?

Hanya sedikit: Faktor berjalan dari 1,5 pada 4 GPU ke 1.75 pada 8 dan 1.98 di 128. Istilah latensi tumbuh linear dengan N.

Apakah cincin satu-satunya algoritme mengurangi?

Tidak. Pohon, pohon biner ganda, hierarkis dan jaringan in- (SHARP) algoritma mengurangi latensi dalam skala; cincin adalah dasar bandwid- optimal digunakan di sini.
