# 逐项任务检查点

每个选中候选建立 `TOOL-xxx.md`。最多一个任务为 IMPLEMENTING；先恢复进行中任务，再选择下一候选。BLOCKED 项要写明解锁条件，条件未变化时不重复审核。

任务必须记录：

1. 负责人、实际模型、输入、输出、依赖及可检查验收标准。
2. 当前阶段与状态（ADMISSION / IMPLEMENTING / REVIEW / BLOCKED / LOCAL_ACCEPTED），以及当前独立 Agent ID。
3. 准入证据、来源与方法、计划测试，以及独立审核的完整结论路径。
4. 实际改动、已运行测试、日志路径和恢复下一步。
5. 失败位置、原因、连续修复次数，以及第三次失败后的新诊断结果。

完成后保留任务文件和证据。没有证据不能将状态改为 LOCAL_ACCEPTED；已有工具覆盖项记录为排除，不能伪装成新工具完成。
