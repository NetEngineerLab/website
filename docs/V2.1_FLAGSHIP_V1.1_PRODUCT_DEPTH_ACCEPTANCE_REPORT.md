## Product-depth upgrades

- Four-step guided workflow: Observe → Intent → Plan → Verify.
- Four representative engineering cases covering Cisco, Huawei, Juniper and Arista deployment patterns.
- Input-readiness checklist and clearer device/port guidance.
- Result explanation layer that translates semantic drift and risk into operational meaning.
- Expandable risk-factor explanations with scoring reasons.
- Copyable MOP document generated from the same plan object used by the execution engine.
- Markdown MOP export.
- Print / Save PDF layout using browser print, with a dedicated print stylesheet.
- Improved mobile experience for long configurations, runbooks, actions and step navigation.
- No change to the proven managed-domain engine boundaries: LAG + trunk/VLAN only.
