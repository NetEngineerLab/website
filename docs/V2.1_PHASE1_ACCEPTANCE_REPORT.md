## Strengthened validation

The final Workflow validator now blocks release when:

- an active tool is not covered by any workflow;
- a workflow references a missing or inactive tool;
- workflow step order is duplicated or non-contiguous;
- bilingual workflow/action copy is missing;
- a Related target is missing, inactive, duplicated or self-referential;
- Previous / Next points to an invalid tool;
- generated `tool-graph.json` differs from canonical registries;
- generated `tools-catalog.json` differs from Tool Registry V2;
- a bilingual tool page is missing its Tool Graph navigation block;
- a legacy hand-written `#related` section remains;
- a production tool route is missing from sitemap;
- stale 20-tool homepage/directory copy reappears.
