## Safety behavior

- Explicit device ID is required.
- Explicit port group plus port/index is required when a device has multiple groups.
- Out-of-range ports fail closed.
- Ambiguous selectors fail closed.
- Port groups without sufficiently safe automatic interface naming fail closed (`manual-required`).
- The resolver never translates an interface string from one vendor into another.
