# NetEngineerLab V1.8.1 GA4 Hotfix 01

## Purpose

Restore production Google Analytics 4 tracking after the site configuration
regressed to a disabled placeholder value and the shared analytics loader
raised a runtime error.

## Production configuration

- Measurement ID: `G-KGNFX9MD8Q`
- Loader: `website/assets/js/analytics.js`
- Source of truth: `website/data/site-config.json`
- Generated runtime configuration: `website/data/site-config.js`
- Consent: denied by default; GA4 loads only after the visitor accepts cookies
- Production hosts: `netengineerlab.com` and `www.netengineerlab.com`

## Regression protection

`npm run test:ga4` validates the source configuration, generated configuration,
Consent Mode defaults, production-host guard, duplicate-loader protection and
the consent-gated loader behavior.

`GA4 Production Monitor` runs after pushes to `main`, once daily, and on manual
dispatch. It checks both the repository configuration and the deployed site.

## Verification

```bat
npm run build:config
npm run test:ga4
```

After Cloudflare Pages finishes deploying:

```bat
npm run check:ga4
```
