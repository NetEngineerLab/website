## Architecture result

The second domain proves the shared platform is not ACL-specific:

```text
ACL Domain Registry ------------------┐
                                      ├─> Shared Vendor Registry Contract
Interface/VLAN Domain Registry -------┘          +
                                         Shared Renderer Engine
```

Each domain owns its parser, renderer and semantic model. Shared Core owns only orchestration and registry contracts.

## Supported portable semantics

- access / trunk
- access VLAN
- trunk allowed VLAN set
- native/PVID VLAN
- optional interface description

## Important boundary

Physical interface identifiers remain vendor-native. Cross-vendor automatic port-name translation is intentionally not implemented because a safe mapping requires a future Platform Profile containing vendor, product family, chassis/slot/port model and interface type.

## Excluded from V1

Hybrid, QinQ, PVLAN, VLAN translation, voice VLAN, SVI/L3 interfaces and platform-specific defaults.
