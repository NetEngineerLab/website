# NetEngineerLab V2.1 Flagship V1.1 — Product Analytics & Funnel Measurement

**Version:** V2.1-Flagship-V1.1-Analytics  
**Date:** 2026-09-06  
**Scope:** Network Change Planner & MOP Generator only  
**Principle:** Measure product behavior without collecting running-config, command output, generated configuration, MOP text, credentials, IP addresses, interface descriptions, or other engineering payload content.

## Measurement goal

Answer five product questions with real usage data:

1. Do first-time users reach a valid change plan?
2. Where do users abandon the workflow?
3. Do users review risk and rollback before execution?
4. Do users actually consume/export the MOP?
5. Do users complete the verification loop, and what decisions result?

## Funnel

1. `tool_opened`
2. `case_loaded` / `input_ready`
3. `plan_built`
4. `risk_reviewed`
5. `rollback_viewed`
6. `mop_viewed` / `mop_used`
7. `verification_started`
8. `verification_evidence_complete`
9. `verification_decided`

Funnel steps are emitted through `change_planner_funnel` once per page view to avoid inflated step counts.

## Events

- `change_planner_view`
- `change_planner_case_load`
- `change_planner_sample_load`
- `change_planner_plan`
- `change_planner_section`
- `change_planner_export`
- `change_planner_verify`
- `change_planner_funnel`

## Safe dimensions

Permitted parameters include:

- `tool`
- `locale`
- `vendor`
- `scenario`
- `result`
- `plan_status`
- `risk_band`
- `risk_score_bucket`
- `section`
- `action`
- `decision`
- `passed`
- `failed`
- `inconclusive`
- `rollback_triggered`
- `evidence_total`
- `step`

Do not add raw configuration, command output, MOP text, interface descriptions, IP data, or user-supplied free text as analytics parameters.

## Recommended GA4 exploration

Build a funnel exploration using `change_planner_funnel` filtered by the `step` parameter. Segment by `locale`, `vendor`, and `risk_band`. Track MOP adoption with `change_planner_export` and verification completion with `change_planner_verify`.

Suggested headline ratios:

- Input-ready rate = `input_ready / tool_opened`
- Plan completion rate = `plan_built / tool_opened`
- Risk review rate = `risk_reviewed / plan_built`
- Rollback review rate = `rollback_viewed / plan_built`
- MOP usage rate = `mop_used / plan_built`
- Verification start rate = `verification_started / plan_built`
- Verification decision rate = `verification_decided / plan_built`

These are product-health metrics, not network-health metrics.
