# NetEngineerLab V2.1 Phase1 — Workflow & Tool Graph Integration Report

**Version:** V2.1-Phase1  
**Modified:** 2026-09-05 16:35:00  
**Scope:** Workflow Schema + Workflow Registry + 5 Main Workflows + Previous / Next / Related Tools integration

## Delivered

- `src/registry/workflow-schema.json` — canonical Workflow Schema V2.1.
- `src/registry/workflow-registry.json` — canonical Workflow Registry V2.
- 5 active engineering workflows:
  1. Optical Link Design Workflow
  2. Optical Fault Isolation Workflow
  3. Enterprise LAN & IP Planning Workflow
  4. PoE & Rack Power Design Workflow
  5. Wireless Access Deployment Workflow
- All 21 active tools are covered by at least one workflow.
- `scripts/workflow-registry.js` validates workflow IDs, status/domain, bilingual copy, contiguous steps, unique tools per workflow and tool references.
- `scripts/generate-tool-graph.js` derives the browser/build Tool Graph from Tool Registry V2 + Workflow Registry V2.
- Generated `website/data/tool-graph.json` and `website/data/tool-graph.js`.
- `scripts/integrate-tool-navigation.js` injects one Registry-driven workflow navigation block into every EN / zh-CN tool page.
- Existing hand-written `#related` blocks are removed/replaced to avoid a second relationship source.
- Every tool page now presents:
  - Current primary workflow and step progress
  - Previous engineering step
  - Next engineering step
  - Related Tools from Tool Registry V2
  - Workflow memberships
- Responsive and print-safe styles added to the shared tool design system.
- Build integration added to `build:config` and `build:i18n`.
- Workflow and navigation contract tests added to `prepare:launch`.
