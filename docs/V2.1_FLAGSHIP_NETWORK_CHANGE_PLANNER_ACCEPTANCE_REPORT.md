## Browser E2E note

A separate `npm run test:browser` attempt was made after the production gate. The Playwright package was available, but the execution container did not contain the required Chromium browser binary, so Playwright could not launch a browser. This was an environment prerequisite failure before page execution, not a product assertion failure. The browser suite should be run in CI or a developer environment with the Playwright browsers installed.
