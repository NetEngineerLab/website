# NetEngineerLab V2.1 Phase2 — Running Config Snapshot + State Reconciliation + Minimal Delta Planner

**Version:** V2.1-Phase2-RunningConfigV1  
**Date:** 2026-09-05  
**Status:** Feature/Core implementation

## Goal

Upgrade Change Planning from manually supplied `currentIntent` to a configuration-analysis workflow:

```text
Current Running Config
        ↓
Supported Snapshot Parser
        ↓
Current Canonical State
        ↓
State Reconciliation
        ↓
Desired Intent
        ↓
Minimal Semantic Delta
        ↓
Forward Commands + Rollback Commands
```

## Supported managed state in V1

V1 intentionally parses only the configuration domains already modeled by NetEngineerLab:

- LAG / aggregate ID
- LACP vs static aggregation mode
- physical member bindings
- aggregate logical interface
- trunk/access mode where present
- trunk allowed VLANs
- native VLAN / PVID
- interface description
- VLAN inventory where the supported syntax exposes numeric VLAN IDs

All other lines are preserved as `opaqueLines`. They are not silently interpreted and are never rewritten by Minimal Delta V1.

## Reconciliation states

- `in-sync`: parsed current state already satisfies desired intent; no commands are emitted.
- `drift`: supported current state differs from desired state; minimal delta is generated.
- `blocked`: a safety conflict exists, such as a desired physical member being bound to another aggregate or a required VLAN missing from a known VLAN inventory.

## Minimal Delta principles

The planner does not teardown/recreate a healthy aggregate when only a small semantic change is required.

Examples:

- member added → add only that member
- member removed → detach only that member
- VLAN added → add/update VLAN membership only
- VLAN removed → remove VLAN membership only
- native VLAN changed → modify native/PVID only
- description changed → modify description only
- no semantic drift → NOOP

Rollback is generated as the inverse of the exact supported-state delta.

## Safety boundary

V1 is intentionally fail-closed for malformed managed syntax. Unsupported unrelated syntax stays opaque instead of causing speculative interpretation.

The parser is not a full vendor configuration grammar and must not be presented as one. It is a domain-scoped snapshot parser for the configuration domains NetEngineerLab currently owns.
