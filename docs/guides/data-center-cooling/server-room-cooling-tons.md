# Server Room Cooling Tons — Quick Conversion

## Conversion

```text
Refrigeration tons (RT) = Design cooling load (kW) ÷ 3.51685
BTU/h = Design cooling load (kW) × 3412.142
```

A 159.25 kW design sensible load is approximately 45.3 RT or 543,390 BTU/h.

The converted load is not automatically the equipment nameplate to purchase. Match it against manufacturer **sensible** capacity at expected entering-air, ambient, altitude and airflow conditions, then add the required redundant units.
