# NetEngineerLab V2.1 Phase2 — Device Platform Catalog + Port Map + Interface Resolver

Status: implemented

## Architecture

Canonical Intent → Device Platform Catalog → Port Group / Port Map → Interface Resolver → Platform Profile Capability Gate → Vendor Renderer → Parser → Semantic Round Trip.

## V1 baseline devices

- Cisco C9200L-24T-4G
- Huawei CloudEngine S5735-L24T4S-A1
- H3C S5130S-28P-EI
- Juniper EX3400-24T
- Arista 7050SX3-48YC8

## Safety boundary

The resolver never translates one vendor interface string into another. It resolves an explicit device ID plus a physical selector against that device's own port map. Port groups whose interface naming is not sufficiently stable/verified are cataloged but marked manual-required; automatic resolution fails closed.

## V1 exclusions

Stack member selection other than the baseline member, chassis line cards, breakout lanes, LAG/AE/Port-Channel, combo-port mutual exclusion, transceiver compatibility and live inventory discovery are deferred.
