# NetEngineerLab V2.1 Phase2 — Platform Profile V1

## Purpose

Platform Profile V1 adds a device/platform-aware validation layer between the canonical Interface/VLAN model and vendor renderers.

Pipeline:

Canonical Interface/VLAN Model → Platform Profile Capability Gate → Shared Vendor Renderer Engine → Vendor Renderer → Parser → Semantic Round Trip

## Baseline profiles

- Cisco IOS Campus Switch
- Huawei VRP Campus Switch
- H3C Comware Campus Switch
- Juniper Junos ELS Switch
- Arista EOS Switch

Each profile defines vendor ownership, platform family, accepted interface-name patterns, interface types and a capability matrix for access/trunk/native VLAN/allowed VLAN/description.

## Important boundary

Platform Profile V1 validates interface naming and platform capability; it does not translate physical port identity between vendors. Port mapping requires an explicit device inventory / port map layer in a later phase.
