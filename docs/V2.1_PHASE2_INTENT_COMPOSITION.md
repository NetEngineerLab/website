# NetEngineerLab V2.1 Phase2 — Intent Composition V1

Status: Implemented

## Goal
Convert one engineering intent into an ordered device configuration plan instead of making users generate LAG and trunk configuration separately.

## Pipeline

Canonical Composite Intent → Device Catalog → Topology Resolver → LAG Canonical Model → Vendor LAG Renderer → Aggregate Interface → Platform Profile Capability Gate → Interface/VLAN Canonical Model → Vendor VLAN Renderer.

## Dependency graph

1. Resolve physical members.
2. Create the logical aggregate.
3. Configure trunk/VLAN semantics on the logical aggregate.

The engine fails closed on invalid VLAN semantics, member speed mismatch, invalid topology selectors, unsupported interface names, or platform capability violations.
