## Accepted scope

- Five-vendor verification output parsing: Cisco IOS, Huawei VRP, H3C Comware, Juniper Junos, Arista EOS.
- Vendor-neutral evidence extraction for aggregate state/member count, logical-interface state/errors, trunk VLAN/native-PVID state, and VLAN inventory.
- Execution result evaluation: `PASS`, `FAIL`, `ROLLBACK_REQUIRED`, `INCONCLUSIVE`.
- Explicit rollback-trigger mapping for aggregate down, member-count mismatch, trunk semantic mismatch, unexpected members, and interface errors.
- Missing/partial output is fail-closed as `INCONCLUSIVE`, never PASS.
- `change-execution/engine.js` exposes `evaluateOutputs()` for closed-loop MOP evaluation.
