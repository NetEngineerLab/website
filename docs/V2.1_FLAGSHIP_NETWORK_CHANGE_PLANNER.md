# NetEngineerLab V2.1 Flagship Tool — Network Change Planner & MOP Generator

Status: Feature/Core implementation
Date: 2026-09-05

## Product goal

Expose the V2 state-aware change stack as the 22nd production tool.

## Managed V1 domain

- Running-config snapshot parsing for the tested LAG + trunk/VLAN subset
- Device/model aware member selection
- State reconciliation and conflict blocking
- Minimal forward and rollback configuration
- Deterministic risk score
- Pre/post verification runbook
- Post-check evidence evaluation: PASS / FAIL / ROLLBACK_REQUIRED / INCONCLUSIVE

## Safety boundary

The tool does not claim to manage arbitrary running-config domains. Unsupported context remains unmanaged and production execution still requires operator approval and vendor/site procedures.
